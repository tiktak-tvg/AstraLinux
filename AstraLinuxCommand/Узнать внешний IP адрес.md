#### Простые варианты (рекомендуется):
```bash
curl ifconfig.me
```
или
```bash
curl icanhazip.com
```
или
```bash
curl ident.me
```
С дополнительными параметрами:
-	Для чистого вывода (только IP, без лишних символов):
```bash
curl -s ifconfig.me
```
-	С таймаутом (если сервер долго не отвечает):
```bash
curl -s --max-time 10 icanhazip.com
```
-	Через IPv4 (если curl пытается использовать IPv6):
```bash
curl -4 icanhazip.com
```
> Пример результата:
```text
123.45.67.89
```
##### Как это работает?
Сервисы вроде ifconfig.me или icanhazip.com возвращают только ваш внешний IP-адрес, который видят серверы в интернете. Это удобно для скриптов и быстрой проверки.

Если команда не работает:

1.	Убедитесь, что установлен curl:
```bash
curl --version
```
2.	Попробуйте другой сервис (например, api.ipify.org):
```bash
curl api.ipify.org
```
