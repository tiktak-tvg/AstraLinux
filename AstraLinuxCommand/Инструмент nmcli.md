### Инструмент nmcli для настройки статического IP-адреса.

Отображение параметров сетевых интерфейсов с помощью nmcli
Прежде чем настраивать статический IP-адрес, нужно узнать, какие подключения доступны в системе. Для этого выполните одну из следующих команд:
```bash
nmcli connection show
```
```bash
nmcli con show
```
Вы должны получить такую информацию:
```bash
NAME — название подключения;
UUID — универсальный уникальный идентификатор;
TYPE — тип подключения;
DEVICE — название сетевого интерфейса.
```

Чтобы отобразить на экране активные и неактивные подключения / интерфейсы, введите в окне терминала команду:
```bash
nmcli dev status
```
#### Установка статического IP-адреса.
Использовав предыдущие команды, мы узнали, что в системе есть только один активный сетевой интерфейс — `ens33`. 

Для него мы и будем настраивать статический IP-адрес. Сначала узнаем его текущий IP-адрес:
```bash
ip addr
```
Как видно, текущий IP-адрес — 192.168.59.130/24. Теперь для сетевого интерфейса ens33 установим следующие новые значения:
```bash
Статический IP-адрес — 192.168.59.120/24;
Шлюз по умолчанию — 192.168.59.1;
DNS-сервер — 8.8.8.8.
```
Установим значение IP-адреса с помощью команды:
```bash
nmcli con mod 'Wired Connection 1' ipv4.addresses 192.168.59.120/24
``` 
Настроим шлюз по умолчанию, используя:
```bash
nmcli con mod 'Wired Connection 1' ipv4.gateway 192.168.59.1
```
Также установим новое значение IP-адреса DNS-сервера:
```bash
nmcli con mod 'Wired Connection 1' ipv4.dns '8.8.8.8'
``` 
В конце настроим метод конфигурации IP, как статический:
```bash
nmcli con mod 'Wired Connection 1' ipv4.method manual
```
Чтобы внесенные изменения заработали, нужно заново поднять (включить) сетевой интерфейс. Для этого выполним команду:
```bash
nmcli con up 'Wired Connection 1'
```
Теперь проверим текущее значение IP-адреса сетевого интерфейса:
```bash
ip addr show ens33
```
>Как Вы видите, выводе содержит ранее установленный статический IP-адрес.
