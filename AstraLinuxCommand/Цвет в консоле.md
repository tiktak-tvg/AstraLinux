#### Как сделать, чтобы команды выводились не в чёрно-белом исполнении, а в подсвечивались

Например, ``ls -la`` как подцветить цветом в консоле

##### Разовое использование

Просто добавьте флаг --color:
```bash
ls -la --color=auto
```
(В macOS вместо --color используется флаг -G: ls -laG)

##### Сделать цвета постоянными (Alias)
Чтобы не вводить флаг каждый раз, создайте «псевдоним» (alias) в конфигурационном файле вашего интерпретатора (обычно это .bashrc или .zshrc):

Откройте файл для редактирования:
```bash
nano ~/.bashrc
```
Добавьте в конец файла строку:
```bash
alias ls='ls --color=auto'
```
Сохраните изменения (Ctrl+O, Enter, Ctrl+X) и обновите конфигурацию:
```bash
source ~/.bashrc
```
Но там и так есть закомментированые строки 
```bash
# You may uncomment the following lines if you want `ls' to be colorized:
# export LS_OPTIONS='--color=auto'
# eval "`dircolors`"
# alias ls='ls $LS_OPTIONS'
# alias ll='ls $LS_OPTIONS -l'
# alias l='ls $LS_OPTIONS -lA'
#
# Some more alias to avoid making mistakes:
# alias rm='rm -i'
# alias cp='cp -i'
# alias mv='mv -i'
```
можно просто снять комментарий
```bash
nano ~/.bashrc

export LS_OPTIONS='--color=auto'
eval "`dircolors`"
alias ls='ls $LS_OPTIONS'
```
> Кстати, хотите заодно раскомментировать ``alias ll='ls $LS_OPTIONS -l'``, чтобы вводить всего две буквы вместо ``ls -l``

##### А как сделать цветным ip
Чтобы ip a всегда был цветным, добавьте алиас в тот же файл `` ~/.bashrc``:
- **Добавьте алиас**
Откройте файл:
```bash
nano ~/.bashrc
```
Добавьте в блок с алиасами (где вы только что правили ls) строку:
```bash
alias ip='ip -c'
```
- **Примените изменения**
```bash
source ~/.bashrc
```
