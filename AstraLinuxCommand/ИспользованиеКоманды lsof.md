### Утилита lsof (от англ. List Open Files) — инструмент командной строки Linux, предназначенный для отображения информации о файлах, которые в данный момент используются процессами в ОС.

#### Вывод на экран всех открытых файлов в ОС.

Чтобы отобразить в терминале список всех используемых файлов в операционной системе, выполните команду lsof без каких-либо опций и аргументов:
```bash
lsof
```
Утилита lsof по умолчанию выводит следующую информацию о каждом файле:

- COMMAND — название процесса или команды, которая использует файл;
- PID — идентификатор процесса;
- USER — пользователь, которому принадлежит процесс;
- FD — дескриптор файла (например, cwd — текущий рабочий каталог, txt — исполняемый код, mem — отображенные в память файлов, rtd — корневой каталог);
- TYPE — тип файла или объекта файловой системы (например, REG — обычный файл, DIR — каталог, и другие);
- DEVICE — мажорный и минорный номера устройства, на котором находится файл;
- SIZE/OFF — размер файла или значение смещения в нем;
- NODE — номер индексного дескриптора (inode);
- NAME — абсолютный путь к файлу.

#### Отображение файлов, используемых конкретным пользователем.
```bash
lsof -u user
```
#### Поиск процессов, которые прослушивают сетевые порты.

Возможность определения процессов, прослушивающих какой-либо порт. Для этой задачи Вам нужно использовать команду вместе с опцией -i
```bash
lsof -i
```
#### Вывод файлов, открытых процессами определенного пользователя, которые используют сетевые соединения.

Вы можете объединить опции -i и -u, чтобы вывести на экран информацию о файлах, открытых процессами конкретного пользователя, использующих сетевые соединения. 
>Например:
```bash
lsof -i -u user
```
