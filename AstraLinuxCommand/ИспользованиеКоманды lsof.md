### Утилита lsof (от англ. List Open Files) — инструмент командной строки Linux, предназначенный для отображения информации о файлах, которые в данный момент используются процессами в ОС.

#### Вывод на экран всех открытых файлов в ОС.

Чтобы отобразить в терминале список всех используемых файлов в операционной системе, выполните команду lsof без каких-либо опций и аргументов:
```bash
lsof
```
Утилита lsof по умолчанию выводит следующую информацию о каждом файле:

- COMMAND — название процесса или команды, которая использует файл;
- PID — идентификатор процесса;
- USER — пользователь, которому принадлежит процесс;
- FD — дескриптор файла (например, cwd — текущий рабочий каталог, txt — исполняемый код, mem — отображенные в память файлов, rtd — корневой каталог);
- TYPE — тип файла или объекта файловой системы (например, REG — обычный файл, DIR — каталог, и другие);
- DEVICE — мажорный и минорный номера устройства, на котором находится файл;
- SIZE/OFF — размер файла или значение смещения в нем;
- NODE — номер индексного дескриптора (inode);
- NAME — абсолютный путь к файлу.

#### Отображение файлов, используемых конкретным пользователем.
```bash
lsof -u user
```
#### Поиск процессов, которые прослушивают сетевые порты.

Возможность определения процессов, прослушивающих какой-либо порт. Для этой задачи Вам нужно использовать команду вместе с опцией -i
```bash
lsof -i
```
#### Вывод файлов, открытых процессами определенного пользователя, которые используют сетевые соединения.

Вы можете объединить опции -i и -u, чтобы вывести на экран информацию о файлах, открытых процессами конкретного пользователя, использующих сетевые соединения. 
>Например:
```bash
lsof -i -u user
```
#### Исключение файлов определенного пользователя.
Можно исключить процессы определенного пользователя из вывода `lsof`.<br> 
Для этого напишите перед именем пользователя специальный символ `^`. <br>
>Например:
```bash
lsof -i -u ^root
```
#### Поиск процессов, работающих на определенном сетевом порту.
Чтобы вывести на экран информацию о процессах, которые работают на определенном порту, выполните в терминале следующую команду:
```bash
lsof -i <port-type>:<port-number>
``
Где:

- <port-type> — тип сетевого протокола, связанного с портом (TCP или UDP);
- <port-number> — номер сетевого порта.

Например, узнаем, какие процессы прослушивают TCP-порты 22 и 80:

```bash
lsof -i TCP:22
lsof -i TCP:80
```
Вы можете не указывать тип порта. Тогда утилита lsof выведет на экран процессы, использующие протоколы TCP и UDP.

#### Просмотр процессов, работающих на сетевых портах определенного диапазона.
Вы можете вывести на экран список процессов, которые прослушивают сетевые порты из определенного диапазона. Для этого модифицируйте предыдущую команду следующим образом:
```bash
lsof -i <port-type>:<start-port>-<end-port>
lsof -i TCP:22-1024
```
#### Поиск процессов, использующих сетевые соединения IPv4 и IPv6.
Команда lsof поможет Вам узнать информацию о файлах, открытых процессами, использующими сетевые соединения IPv4. Для этого выполните следующую команду:
```bash
lsof -i 4
```
Чтобы вывести на экран процессы, которые обмениваются данными по сети IPv6, замените аргумент 4 на 6:
```bash
lsof -i 6
```
#### Вывод списка файлов, используемых определенным процессом.
Опция -p команды lsof позволяет Вам вывести на экран информацию о файлах, которые открыты конкретным процессом. <br>Для примера узнаем, какие файлы использует процесс с идентификатором 1:
```bash
lsof -p 1
```
#### Завершение всех процессов пользователя.
Вы можете вывести на экран только идентификаторы процессов, запущенных конкретным пользователем. <br>Для этого Вам нужно использовать команду `lsof` с опциями `-t` и `-u`. 

>Например:
```bash
lsof -t -u user
```
Чтобы завершить все процессы пользователя, передайте в качестве аргумента для команды `kill -9 ` предыдущую команду:
```bash
kill -9 $(lsof -t -u user)
```
