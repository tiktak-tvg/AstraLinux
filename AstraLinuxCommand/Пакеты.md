#### Как обновить системные пакеты.
```bash
apt-get update
```
#### Как обновить пакеты программного обеспечения.
```bash
apt-get upgrade
apt-get dist-upgrade
```
#### Как установить или обновить конкретные пакеты.
```bash
apt-get install dnsutils
```
#### Как установить несколько пакетов одновременно.
```bash
apt-get install dnsutils nethogs
```
#### Как установить пакеты без их обновления.

Возможно, при установке ПО Вам не захочется обновлять все пакеты. 
```bash
apt-get install имяпакета --no-upgrade
```
#### Как не устанавливать, а только обновить пакеты.
```bash
apt-get install имяпакета --only-upgrade
```
#### Как установить конкретную версию пакета.

Также часто возникает необходимость в установке определенной версии выбранного пакета.<br> 
Сделать это совсем просто — добавьте после имени пакета символ «=» (знак равенства) и укажите после него желаемую версию.
```bash
apt-get install vsftpd=2.3.5-3ubuntu1
```
#### Как удалить пакет без очистки его настроек.

Предположим, что Вы хотите удалить тот или иной пакет программного обеспечения.<br> 
Однако предполагаете, что в будущем будете использовать его снова и не хотите терять актуальные файлы настроек.<br>
Самый удобный способ сделать это — `опция remove`.
```bash
apt-get remove vsftpd
```
#### Как полностью удалить пакет.

некоторые пакеты Вы будете удалять раз и навсегда, а потому нет смысла засорять память компьютера лишними файлами настроек. <br>
На такой случай есть соответствующая опция команды — `purge`.
```bash
apt-get purge vsftpd
apt-get remove --purge vsftpd
```
#### Как загрузить только исходный код пакета.
Также опытные пользователи могут захотеть загрузить лишь исходный код указанного пакета.<br> 
Для решения подобной задачи используется опция `–download-only source`. 
```bash
apt-get --download-only source vsftpd
```
#### Как загрузить и распаковать пакет.

Вам может потребоваться загрузить и распаковать исходный код ПО в указанный каталог.<br> 
Для решения такой задачи введите следующую команду с опцией `source`.
```bash
apt-get source vsftpd
```
#### Как загрузить, распаковать и скомпилировать пакет.

Существует возможность скачать, распаковать и скомпилировать исходный код пакета.<br>  
Для этого есть отдельная опция — `--compile`.
```bash
apt-get --compile source vsftpd
```
#### Как загрузить и не устанавливать пакеты.
Предположим, что Вы желаете загрузить, но не устанавливать тот или иной набор ПО.<br> 
Безусловно, и такая возможность была предусмотрена создателями менеджера `apt-get`.<br> 
Просто воспользуйтесь опцией `download`.
```bash
apt-get download nethogs
```
#### Как проверить журнал изменения пакетов.

Довольно часто Вам придется сверять версии пакетов, установленных в ОС, а также искать те из них, которые изменились. <br>
Для этой цели предусмотрена опция `changelog`
```bash
apt-get changelog vsftpd
```
#### Как выполнить поиск неисправностей.

Бывает и так, что некоторые пакеты работают некорректно. 
```bash
apt-get check
```
#### Как искать и строить зависимости.
Полезной для Вас может оказаться опция build-dep, которая примечательна тем, что выполняет поиск локальных репозиториев в системе и устанавливает все зависимости пакета.<br>  
Однако в том случае, если пакет отсутствует в локальном репозитории — будет выведен код ошибки. 
```bash
apt-get build-dep netcat
```
#### Как быстро очистить apt-get cache.

В работе с Linux может возникнуть потребность в очистке кэша.<br> 
На такой случай предусмотрена опция autoclean, которая очищает содержимое каталога `/var/cache/apt/archives` (все файлы .deb) и позволяет освободить занятое ими дисковое пространство.
```bash
apt-get autoclean
```
#### Как автоматически удалить установленные пакеты.

После удаления некоторых пакетов в системе могут остаться их зависимости.
```bash
apt-get autoremove vsftpd
```
