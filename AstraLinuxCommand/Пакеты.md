#### Как просмотреть все доступные пакеты.
Например,  
```bash
apt-cache pkgnames
```
![image](https://github.com/user-attachments/assets/7e663fcd-505a-4e46-b687-d81e6b122f14)

#### Как узнать имя пакета и описание программного обеспечения.
```bash
apt-cache search dnsutils
apt-cache search ttf-mscorefonts-installer
apt-cache search vsftpd
```
![image](https://github.com/user-attachments/assets/b836827b-2ff1-4731-9456-29a8d8b74b6d)

#### Как посмотреть информацию о пакете
Предположим, что Вас интересует следующая информация о выбранном пакете:<br>
- номер версии;
- размер;
- зависимости;
- хэш.
```bash
apt-cache show netcat
```
![image](https://github.com/user-attachments/assets/8436379e-9716-43b6-8456-acc4364e335c)

#### Как проверить зависимости для конкретных пакетов.
```bash
apt-cache showpkg ttf-mscorefonts-installer
apt-cache show ttf-mscorefonts-installer
```
![image](https://github.com/user-attachments/assets/7868ce3d-056a-4b34-8d75-d148ae12c053)

#### Как проверить статистику кэша.
```bash
apt-cache stats
```

![image](https://github.com/user-attachments/assets/aa9ddee6-461e-4324-acf8-a7001f874387)

#### Как обновить системные пакеты.
```bash
sudo apt-get update
```
#### Как обновить пакеты программного обеспечения.
```bash
sudo apt-get upgrade
sudo apt-get dist-upgrade
```
