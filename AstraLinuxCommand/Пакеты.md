#### Как просмотреть все доступные пакеты.
Например,  
```bash
apt-cache pkgnames
```
![image](https://github.com/user-attachments/assets/7e663fcd-505a-4e46-b687-d81e6b122f14)

#### Как узнать имя пакета и описание программного обеспечения.
```bash
apt-cache search dnsutils
apt-cache search ttf-mscorefonts-installer
apt-cache search vsftpd
```
![image](https://github.com/user-attachments/assets/b836827b-2ff1-4731-9456-29a8d8b74b6d)

#### Как посмотреть информацию о пакете
Предположим, что Вас интересует следующая информация о выбранном пакете:<br>
- номер версии;
- размер;
- зависимости;
- хэш.
```bash
apt-cache show netcat
```
