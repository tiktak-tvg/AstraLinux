### P.S. Всегда делайте резервную копию перед редактированием
#### Способ 1: Использование sed (рекомендуется)
###### Раскомментировать ВСЕ строки, начинающиеся с #deb для репозиториев
```bash
sudo sed -i 's/^#deb https:\/\/download\.astralinux\.ru\//deb https:\/\/download\.astralinux\.ru\//' /etc/apt/sources.list
```
###### ИЛИ раскомментировать только определенные репозитории:
```bash
sudo sed -i '/repository-main/s/^#//' /etc/apt/sources.list
sudo sed -i '/repository-update/s/^#//' /etc/apt/sources.list
sudo sed -i '/repository-base/s/^#//' /etc/apt/sources.list
sudo sed -i '/repository-extended/s/^#//' /etc/apt/sources.list
```
#### Способ 2: Одной командой для всех
###### Раскомментировать все 4 репозитория сразу
```bash
sudo sed -i -e 's/^#deb https:\/\/download\.astralinux\.ru\/astra\/stable\/1\.7_x86-64\/repository-main\//deb https:\/\/download\.astralinux\.ru\/astra\/stable\/1\.7_x86-64\/repository-main\//' \
           -e 's/^#deb https:\/\/download\.astralinux\.ru\/astra\/stable\/1\.7_x86-64\/repository-update\//deb https:\/\/download\.astralinux\.ru\/astra\/stable\/1\.7_x86-64\/repository-update\//' \
           -e 's/^#deb https:\/\/download\.astralinux\.ru\/astra\/stable\/1\.7_x86-64\/repository-base\//deb https:\/\/download\.astralinux\.ru\/astra\/stable\/1\.7_x86-64\/repository-base\//' \
           -e 's/^#deb https:\/\/download\.astralinux\.ru\/astra\/stable\/1\.7_x86-64\/repository-extended\//deb https:\/\/download\.astralinux\.ru\/astra\/stable\/1\.7_x86-64\/repository-extended\//' \
           /etc/apt/sources.list
```
#### Способ 3: С использованием awk
```bash
sudo awk '/^#deb https:\/\/download\.astralinux\.ru\// {sub(/^#/, "")} {print}' /etc/apt/sources.list > /tmp/sources.list && sudo mv /tmp/sources.list /etc/apt/sources.list
```
#### Способ 4: Через временный файл
###### Создать временный файл с изменениями
```bash
sudo cp /etc/apt/sources.list /etc/apt/sources.list.backup
sudo perl -pe 's/^#(deb https:\/\/download\.astralinux\.ru\/)/$1/' /etc/apt/sources.list > /tmp/sources.list.new
sudo mv /tmp/sources.list.new /etc/apt/sources.list
```
#### Способ 5: Для раскомментирования всех deb-строк (кроме CD-ROM)
###### Раскомментировать все строки, начинающиеся с #deb, но не трогать строку с CD-ROM
```bash
sudo sed -i '/^#deb.*download\.astralinux\.ru/s/^#//' /etc/apt/sources.list
```
