### Чтобы скопировать сам файл ISO (а не его содержимое) в папку ubuntu, выполните:
#### 1. Создайте папку ubuntu (если её нет)
```bash
mkdir -p ~/ubuntu
```
#### 2. Скопируйте ISO-файл
```bash
cp путь/к/файл.iso ~/ubuntu/
```
Или с сохранением всех атрибутов:
```bash
cp -p путь/к/файл.iso ~/ubuntu/
```
________________________________________
Примеры:
Копирование из текущей директории:
```bash
cp ubuntu-22.04.iso ~/ubuntu/
```
Копирование из загрузок:
```bash
cp ~/Downloads/ubuntu-image.iso ~/ubuntu/
```
Копирование с переименованием:
bash
cp оригинал.iso ~/ubuntu/новое_имя.iso
```
________________________________________
#### 3. Проверьте результат
```bash
ls -la ~/ubuntu/*.iso
```
________________________________________
Если нужно скопировать несколько ISO-файлов:
```bash
cp *.iso ~/ubuntu/
```
________________________________________
Для копирования между разными разделами/дисками с прогрессом:
```bash
rsync -av --progress файл.iso ~/ubuntu/
```
________________________________________
#### Примечание: Эта команда копирует сам файл образа .iso, а не извлекает его содержимое. Если вам нужно именно содержимое образа, используйте инструкции из предыдущего ответа с монтированием.

### У вас есть устройство sr0 (обычно это CD/DVD привод) с диском. Вот как скопировать образ с этого устройства в папку /mnt/iso:
#### 1. Создайте папку для монтирования (если нужно)
```bash
sudo mkdir -p /mnt/iso
```
#### 2. Смонтируйте устройство sr0
```bash
sudo mount /dev/sr0 /mnt/iso
```
#### 3. Скопируйте содержимое диска
Если вы хотите скопировать файлы с диска:
```bash
sudo cp -r /mnt/iso/* /путь/к/вашей/папке/
```
________________________________________
Но если вам нужен именно ISO-образ устройства, то:
#### 1. Создайте ISO-образ из устройства sr0
```bash
sudo dd if=/dev/sr0 of=/mnt/iso/disk_image.iso bs=2048
```
Или с прогрессом:
```bash
sudo dd if=/dev/sr0 of=/mnt/iso/disk_image.iso bs=2048 status=progress
```
________________________________________
#### Альтернативные способы создания ISO:
С помощью cat:
```bash
sudo cat /dev/sr0 > /mnt/iso/disk_image.iso
```
С помощью pv (с индикатором прогресса):
```bash
sudo apt install pv
sudo pv /dev/sr0 > /mnt/iso/disk_image.iso
```
С помощью genisoimage (если нужно создать образ):
```bash
sudo genisoimage -o /mnt/iso/disk_image.iso /dev/sr0
```
________________________________________
Проверка результата:
```bash
ls -lh /mnt/iso/disk_image.iso
```
Должен показать файл размером около 4.4G.
________________________________________
После копирования размонтируйте устройство:
```bash
sudo umount /dev/sr0
```
