### При запуске скрипта sh выдаёт ошибку
Рассмотрим наиболее частые ошибки и их решения:

#### 1. Синтаксические ошибки
```syntax error near unexpected token```
-	Проверьте кавычки (должны быть парные)
-	Проверьте пробелы вокруг = при присваивании переменных

#####  Неправильно:
```bash
var = "value"
```
#####  Правильно:
```bash
var="value"
```
#### 2. Проблемы с шебангом
```bad interpreter: No such file or directory```
#####  Убедитесь, что путь правильный
```
which bash
```
#####  Обычно /bin/bash или /usr/bin/bash
####  Или используйте:
```
#!/usr/bin/env bash
```
#### 3. Проблемы с форматом файла
```command not found (в странных местах)```
#####  Проверить формат файла
```bash
file script.sh
cat -v script.sh
```
#####  Конвертировать из Windows в Unix
```bash
sed -i 's/\r$//' script.sh
```
или
```
dos2unix script.sh
```
#### 4. Отсутствующие команды
```command not found```
#####  Проверить доступность команды
```bash
which ls
```
#####  Установить отсутствующие пакеты
#### 5. Проблемы с путями
#####  Всегда используйте полные пути в скриптах
```bash
/home/user/script.sh
```
#####  или переходите в директорию сначала
```bash
cd /path/to/directory && ./script.sh
```
#### 6. Быстрая диагностика
#####  Проверить синтаксис
```bash
bash -n your_script.sh
```
#####  Запустить с подробной отладкой
```
bash -x your_script.sh
```
#####  Проверить все переменные
```
set
```
