### Командная строка — это основной инструмент администратора Astra Linux. 
В отличие от графических утилит, она даёт полный контроль над системой и позволяет автоматизировать рутинные задачи.

#### 📝 Структура командной строки
Командная строка в Astra Linux (как и в любом Linux) строится по единому шаблону:

```text
[приглашение] команда [параметры] [аргументы]
Приглашение (prompt) — это строка, которую оболочка выводит перед вводом команды. В Astra Linux оно выглядит так:
```
```text
имя_пользователя@имя_хоста:текущий_каталог$
```
> - Например: 

localadmin@astra:~$

localadmin — имя пользователя;

astra — имя хоста;

~ — текущий каталог (домашний);

$ — символ окончания приглашения для обычного пользователя (# — для root).

Команда — это исполняемый файл или встроенная функция оболочки (например, ls, cd, echo).

Параметры (опции) — уточняют поведение команды. Бывают короткие (-l) и длинные (--long).

Аргументы — объекты, над которыми выполняется команда (файлы, каталоги, строки).

```bash
ls -l /home/user
#   ^^ ^^^^^^^^^^
#   |  аргумент
#   параметр
```
#### ⚙️ Форматы записи параметров
В Astra Linux (bash) параметры записываются в нескольких формах:

Формат              | Пример                 | Описание
------------------- | ---------------------- | -------------------------
Короткий	        | ls -l	    | Один символ после дефиса.
Объединённый	    | ls -la	| Несколько коротких параметров вместе (эквивалентно -l -a).
Длинный	            | ls --all	| Слово после двух дефисов.
С аргументом	    | grep -e "pattern" file	| Параметр требует значение.
Длинный             | с = grep --regexp="pattern" file	| Значение через знак равенства.

> Важно: Порядок параметров и аргументов обычно не критичен, но некоторые команды требуют строгого порядка.

#### 📦 Работа с переменными
Переменные в bash — это именованные области памяти. Они не требуют объявления типа.

##### Определение и использование
```bash
# Присваивание (без пробелов вокруг =)
NAME="Astra Linux"
VERSION=1.7

# Использование
echo "Дистрибутив: $NAME, версия: $VERSION"
```
##### Переменные окружения
Переменные окружения наследуются дочерними процессами. Для их создания используется export:
```bash
export MY_VAR="value"
```
##### Основные переменные окружения:

Переменная          | Назначение                
------------------- | --------------------
PATH	            | Список каталогов для поиска исполняемых файлов.
HOME	            | Домашний каталог пользователя.
USER	            | Имя текущего пользователя.
PWD	                | Текущий рабочий каталог.
SHELL	            | Текущая оболочка.

##### Настройка переменных окружения в Astra Linux:
Пользовательские переменные задаются в файле ~/.profile. Например, для добавления каталога в PATH:
```bash
PATH=/opt/wine-6.17:$PATH
```
##### Применить изменения без перезапуска сессии:
```bash
source ~/.profile
```
Системные переменные задаются в /etc/profile и скриптах в /etc/profile.d/. 
##### Системные переменные должны быть экспортированы:
```bash
PATH="/usr/local/bin:/usr/bin:/bin"
export PATH
```
##### Специальные переменные

Переменная          | Значение               
------------------- | --------------------
$0	                | Имя сценария или оболочки.
$1, $2, ...	        | Аргументы командной строки.
$#	                | Количество аргументов.
$?	                | Код возврата последней команды.
$$	                | PID текущего процесса.

#### 🔍 Символы подстановки в именах файлов и командная подстановка
##### Символы подстановки (globbing)
Оболочка ``bash`` может подставлять имена файлов по шаблону — этот процесс называется ``globbing``.

Символ              | Значение                                                      | Пример
------------------- | ------------------------------------------------------------- | ------------------------------------------------
*	                | Любое количество любых символов (включая ноль).	            | ls *.txt — все .txt файлы.
?	                | Ровно один любой символ.	                                    | ls file?.txt — file1.txt, file2.txt.
[abc]	            | Один из перечисленных символов.	                            | ls [abc]* — файлы, начинающиеся с a, b или c.
[a-z]	            | Диапазон символов.	                                        | ls [0-9]* — файлы, начинающиеся с цифры.
[!abc]	            | Любой символ, кроме перечисленных.	                        | ls [!a]* — файлы, не начинающиеся с a.
{a,b,c}	            | Одна из перечисленных строк.	                                | ls *.{jpg,png} — файлы .jpg и .png.


> - Важно: Символ * не включает файлы, начинающиеся с точки (скрытые). Для их включения нужно явно указать точку в шаблоне: ls .*.

##### Командная подстановка
Командная подстановка позволяет использовать вывод одной команды как аргумент другой. Два способа:
```bash
# Способ 1: обратные кавычки (устаревший)
echo "Сегодня $(date +%Y-%m-%d)"

# Способ 2: $() (рекомендуемый)
TODAY=$(date +%Y-%m-%d)
echo "Сегодня: $TODAY"

# Пример: подсчёт файлов в каталоге
COUNT=$(ls -1 /etc | wc -l)
echo "В /etc $COUNT файлов"
```
#### 🧮 Выполнение арифметических вычислений
Bash поддерживает целочисленную арифметику. Для вычислений с плавающей точкой используются внешние утилиты.

##### Арифметическое расширение $(( ))
```bash
A=5
B=3

SUM=$((A + B))       # 8
DIFF=$((A - B))      # 2
MUL=$((A * B))       # 15
DIV=$((A / B))       # 1 (целочисленное деление)
MOD=$((A % B))       # 2 (остаток)
POW=$((A ** B))      # 125 (возведение в степень)
```
##### Команда let
```bash
let "RESULT = A + B"
echo $RESULT    # 8
```
##### Команда expr (устаревшая)
```bash
expr 5 + 3       # 8
expr 10 / 3      # 3
expr 3 \* 5      # 15 (звёздочку нужно экранировать)
```
##### Утилита bc (для плавающей точки)
```bash
echo "scale=2; 10 / 3" | bc    # 3.33
echo "sqrt(2)" | bc -l          # 1.41421356237309504880
```
#### 🚫 Отмена значений специальных символов
Специальные символы (*, ?, $, \, ", ', ;, |, &, >, <, (, )) имеют особое значение для оболочки. Чтобы использовать их буквально, нужно экранирование.

Способ	Пример	Описание
Способ              | Пример                 | Описание
------------------- | ---------------------- | -------------------------
Обратный слэш	    | echo \$HOME	    | Выведет $HOME, а не значение переменной.
Одинарные кавычки	    | echo '$HOME'	    | Всё внутри — буквально, без подстановок.
Двойные кавычки	    | echo "$HOME"	    | Переменные подставляются, но * и ? — нет.
\ перед символом	    | echo \*	    | Выведет *, а не список файлов.

##### Примеры:
```bash
# Одинарные кавычки: всё буквально
echo 'Сегодня $DATE'    # Сегодня $DATE

# Двойные кавычки: переменные подставляются
echo "Сегодня $DATE"    # Сегодня 2026-09-15

# Экранирование
echo "Стоимость: \$100"  # Стоимость: $100
```
#### 📜 История команд
Bash сохраняет историю введённых команд в файле ~/.bash_history. Это позволяет быстро повторять команды.

Команда / комбинация    | Действие               
----------------------- | --------------------
history	    | Показать всю историю с номерами.
history 10	    | Показать последние 10 команд.
!!	    | Повторить последнюю команду.
!n	    | Выполнить команду с номером n.
!строка	    | Выполнить последнюю команду, начинающуюся с строка.
Ctrl+R	    | Поиск по истории (обратный поиск).
↑ / ↓	    | Навигация по истории.
history -c	    | Очистить историю текущей сессии.
history -w	    | Записать историю в файл.

Пример:
```bash
# Выполнить последнюю команду
!!

# Найти команду, начинающуюся с "apt"
!apt
```
#### 🏷️ Назначение псевдонимов
Псевдоним (alias) — это сокращение для команды или последовательности команд.

##### Создание псевдонима
```bash
alias ll='ls -l'
alias update='sudo apt update && sudo apt upgrade'
alias ..='cd ..'
```
##### Просмотр и удаление
```bash
# Показать все псевдонимы
alias

# Показать конкретный
alias ll

# Удалить
unalias ll
```
##### Постоянные псевдонимы
Чтобы псевдонимы сохранялись между сессиями, добавьте их в ~/.bashrc:
```bash
echo "alias ll='ls -l'" >> ~/.bashrc
source ~/.bashrc
```
> Важно: В Astra Linux файл ~/.bash_aliases может отсутствовать. Определения псевдонимов рекомендуется размещать непосредственно в ~/.bashrc.

#### 🔄 Дополнение команд и имен переменных
Авто дополнение ``(bash completion)`` — это механизм, который позволяет по нажатию Tab дополнять команды, имена файлов, каталогов и переменных.

##### Использование

Действие                | Результат               
----------------------- | --------------------
Tab	                | Дополняет уникальное совпадение.
Tab Tab	                | Показывает все возможные варианты.
Tab после $	                | Дополняет имена переменных.
Tab после ~	                | Дополняет имена пользователей.
Tab после -	                | Показывает доступные параметры команды.

##### Включение авто дополнения в Astra Linux
В Astra Linux автодополнение включено по умолчанию. Если оно не работает, проверьте файл /etc/bash.bashrc — там должна быть строка:
```bash
shopt -oq posix
```
Для пользователя root автодополнение может быть отключено. Чтобы включить его, добавьте в /root/.bashrc:
```bash
if [ -f /etc/bash_completion ]; then
    . /etc/bash_completion
fi
```
#### 💻 Практическая работа
Цель: Освоить структуру команд, работу с переменными, шаблоны имён файлов, историю команд и командную подстановку.

##### Шаг 1. Выполнение команд и работа с переменными
##### Определите текущий каталог и пользователя:
```bash
pwd
whoami
echo $HOME
```
##### Создайте переменную и выведите её:
```bash
MY_NAME="Astra Linux"
echo "Привет, $MY_NAME!"
```
##### Создайте переменную окружения:
```bash
export MY_ENV="test"
env | grep MY_ENV
```
##### Выполните арифметические вычисления:
```bash
A=10
B=3
echo "Сумма: $((A + B))"
echo "Деление: $(echo "scale=2; $A / $B" | bc)"
```
##### Шаг 2. Составление шаблонов имён файлов
##### Перейдите в каталог /etc:
```bash
cd /etc
```
##### Найдите все файлы с расширением .conf:
```bash
ls *.conf | head -5
```
##### Найдите все файлы, имя которых состоит из трёх символов:
```bash
ls ??? 2>/dev/null | head -5
```
##### Найдите файлы, начинающиеся с rc:
```bash
ls rc* | head -5
```
##### Используйте командную подстановку:
```bash
FILES=$(ls /etc/*.conf | wc -l)
echo "В /etc $FILES конфигурационных файлов"
```
##### Шаг 3. Работа с историей команд
##### Просмотрите последние 5 команд:
```bash
history 5
```
##### Повторите последнюю команду:
```bash
!!
```
##### Найдите в истории команду ls:
```bash
history | grep ls
```
##### Выполните команду по номеру:
```bash
!1
```
##### Шаг 4. Назначение псевдонимов
##### Создайте псевдоним:
```bash
alias ll='ls -l'
alias ..='cd ..'
```
##### Проверьте работу:
```bash
ll
cd /tmp
..
```
##### Просмотрите все псевдонимы:
```bash
alias
```
##### Удалите псевдоним:
```bash
unalias ll
```
##### Шаг 5. Дополнение команд
- Наберите apt и нажмите Tab Tab — увидите список доступных подкоманд.
- Наберите ls /et и нажмите Tab — дополнится до /etc/.
- Наберите echo $HO и нажмите Tab — дополнится до $HOME.

##### Шаг 6. Отмена специальных символов
##### Выведите символ * буквально:
```bash

```
##### Выведите значение переменной в одинарных кавычках:

```

```
#### 🛡️ Особенности Astra Linux SE
Мандатный контроль целостности (МКЦ): В SE с включённым МКЦ выполнение команд, изменяющих систему, требует высокого уровня целостности. Обычная пользовательская сессия может не иметь доступа к защищённым ресурсам.

Файлы конфигурации оболочки: В Astra Linux используются стандартные для Debian файлы (~/.bashrc, ~/.profile, /etc/bash.bashrc). Файл ~/.bash_aliases может отсутствовать — псевдонимы рекомендуется размещать в ~/.bashrc.

Автодополнение для root: По умолчанию автодополнение может быть отключено для пользователя root. Для включения добавьте соответствующие строки в /root/.bashrc.

Логирование действий: В защищённых конфигурациях рекомендуется вести аудит команд, выполняемых в терминале, с помощью script или систем аудита (auditd).
