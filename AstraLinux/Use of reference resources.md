### Использование справочных ресурсов в Astra Linux
Умение быстро находить нужную информацию о командах, их параметрах и настройках — ключевой навык администратора. Astra Linux предоставляет несколько уровней справочных ресурсов: от кратких подсказок в оболочке до официальной документации и wiki.

#### 💡 Отслеживание подсказок команд
Bash и большинство утилит предоставляют встроенные механизмы для получения быстрых подсказок прямо в процессе ввода команды.

Автодополнение по Tab
Действие	Результат
Tab	Дополняет уникальное совпадение (имя команды, файла, каталога, переменной).
Tab Tab	Показывает все возможные варианты.
Tab после -	Показывает список доступных параметров команды (если включён bash-completion).
Tab после --	Показывает длинные параметры команды.
Пример:

bash
# Наберите и нажмите Tab Tab
apt-
# Отобразится список: apt-cache, apt-cdrom, apt-config, apt-get, apt-key, apt-mark
Подсказки для параметров
Современные версии bash-completion в Astra Linux умеют подсказывать не только имена команд, но и их параметры:

bash
# Наберите и нажмите Tab
ls --
# Отобразится список: --all, --almost-all, --author, --block-size, ...
Проверка включения bash-completion
bash
# Проверить, загружен ли модуль
type _init_completion 2>/dev/null && echo "bash-completion загружен"

# Включить для root (если отключён)
echo 'if [ -f /etc/bash_completion ]; then . /etc/bash_completion; fi' >> /root/.bashrc
source /root/.bashrc
#### 🛠️ Использование помощи по встроенным в интерпретатор командам
Некоторые команды являются встроенными в оболочку bash (builtins). Они не имеют отдельных исполняемых файлов, поэтому для них нельзя использовать man напрямую — нужно применять help.

Команда help
bash
# Список всех встроенных команд
help

# Справка по конкретной встроенной команде
help cd
help echo
help alias
help export
Пример вывода:

text
$ help cd
cd: cd [-L|[-P [-e]] [-@]] [dir]
    Change the shell working directory.
    ...
Команда type
Позволяет определить, является ли команда встроенной, внешней или псевдонимом:

bash
type cd        # cd is a shell builtin
type ls        # ls is /usr/bin/ls
type ll        # ll is aliased to `ls -l'
type -a echo   # Показать все варианты
Команда compgen
Выводит список доступных команд, встроенных функций, псевдонимов:

bash
# Список всех встроенных команд
compgen -b

# Список всех псевдонимов
compgen -a

# Список всех команд в PATH
compgen -c | head -20

# Список всех функций
compgen -A function
Краткая справка через --help
Многие внешние утилиты поддерживают параметр --help для краткой справки:

bash
ls --help
cp --help
grep --help
Важно: --help не является стандартом. Некоторые утилиты (например, dd) не поддерживают его и требуют обращения к man.

#### 📖 Работа со справочной системой man
man (manual) — это основная справочная система Linux. Она содержит подробные описания команд, системных вызовов, библиотечных функций, форматов файлов и многого другого.

Структура справочных страниц
Страницы man разделены на разделы (sections):

Раздел	Содержание
1	Пользовательские команды (ls, cp, grep).
2	Системные вызовы (ядро).
3	Библиотечные функции (C).
4	Специальные файлы (/dev/*).
5	Форматы файлов и соглашения (/etc/fstab, /etc/passwd).
6	Игры и развлечения.
7	Разное (макросы, стандарты).
8	Команды администрирования (mount, fdisk, systemctl).
9	Подпрограммы ядра.
Основные команды
Команда	Действие
man ls	Открыть справку по команде ls.
man 5 fstab	Открыть справку по формату файла /etc/fstab (раздел 5).
man 8 mount	Справка по административной команде mount.
man -k keyword	Поиск по ключевому слову во всех разделах (аналог apropos).
man -f command	Показать, в каких разделах есть справка (аналог whatis).
man -a command	Показать все страницы по команде.
Навигация внутри man
Клавиша	Действие
↑ / ↓	Прокрутка на строку.
PgUp / PgDn	Прокрутка на страницу.
Space	Прокрутка вперёд на страницу.
b	Прокрутка назад на страницу.
/pattern	Поиск вперёд по шаблону.
?pattern	Поиск назад.
n	Следующее совпадение.
N	Предыдущее совпадение.
g	Перейти в начало.
G	Перейти в конец.
q	Выход.
h	Встроенная справка по навигации.
Утилиты apropos и whatis
bash
# Поиск команд, связанных с "network"
apropos network

# Краткая информация о команде
whatis ls
# ls (1) - list directory contents

# Обновление базы данных man (выполняется автоматически)
sudo mandb

#### 📚 Работа со справочной системой info
info — это более подробная справочная система, основанная на формате Texinfo. Она организована в виде иерархического дерева узлов и часто содержит более полную информацию, чем man.

Основные команды
Команда	Действие
info	Открыть главное меню (список всех разделов).
info ls	Открыть справку по ls.
info coreutils	Открыть раздел о базовых утилитах.
info --apropos=network	Поиск по ключевому слову.
Навигация внутри info
Клавиша	Действие
n	Следующий узел.
p	Предыдущий узел.
u	Вверх к родительскому узлу.
Enter	Перейти по ссылке (под курсором).
l	Вернуться назад.
Space	Прокрутка вперёд.
Del / Backspace	Прокрутка назад.
q	Выход.
?	Справка по навигации.
m	Переход к пункту меню по имени.
g	Переход к узлу по имени.
Связь между man и info
Многие страницы man содержат ссылку внизу:

text
GNU coreutils online help: <https://www.gnu.org/software/coreutils/>
Full documentation <https://www.gnu.org/software/coreutils/ls>
or available locally via: info '(coreutils) ls invocation'
Это означает, что подробная документация доступна через info.

#### 📘 Использование электронной справки Astra Linux
Astra Linux поставляется с собственной электронной справкой, встроенной в графическую среду.

Доступ через меню
В зависимости от версии и среды рабочего стола:

Fly: «Пуск» → «Справка» (или F1 в большинстве приложений).

Классический рабочий стол: «Пуск» → «Стандартные» → «Справка».

Содержание справки
Руководство пользователя.

Руководство администратора.

Описание штатных утилит (fly-admin-*, astra-*).

Решение типовых проблем.

Информация о сертификации и безопасности.

Утилита fly-help
В некоторых версиях Astra Linux доступна команда fly-help, открывающая электронную справку из терминала:

bash
fly-help

#### 📗 Использование официальной документации
Официальная документация Astra Linux — это основной источник достоверной информации, особенно для специфических функций и настроек безопасности.

Где найти
Ресурс	Описание
/usr/share/doc/	Документация установленных пакетов (README, changelog, примеры конфигураций).
/usr/share/doc/<пакет>/README	Краткое описание пакета.
/usr/share/doc/<пакет>/examples/	Примеры конфигурационных файлов.
Компакт-диск с документацией	Поставляется вместе с дистрибутивом (руководства пользователя и администратора в PDF).
Личный кабинет пользователя	На сайте astra.ru доступны актуальные версии документации для зарегистрированных пользователей.
Полезные команды
bash
# Список документации по пакету
dpkg -L <пакет> | grep /usr/share/doc

# Просмотр README
zcat /usr/share/doc/<пакет>/README.gz | less

# Просмотр changelog
zcat /usr/share/doc/<пакет>/changelog.Debian.gz | less

#### 💻 Практическая работа: Навигация по справочной системе
Цель: Освоить все уровни справочных ресурсов Astra Linux — от подсказок в оболочке до официальной документации и wiki.

##### Шаг 1. Подсказки команд в оболочке
Проверьте работу автодополнения:

bash
# Наберите и нажмите Tab Tab
apt-
Проверьте подсказку параметров:

bash
# Наберите и нажмите Tab Tab
ls --
Определите тип команды:

bash
type cd
type ls
type ll
type -a echo

##### Шаг 2. Справка по встроенным командам
Получите список всех встроенных команд:

bash
help
Получите справку по конкретной встроенной команде:

bash
help cd
help export
help alias
Получите краткую справку по внешней команде:

bash
ls --help
grep --help | head -20

##### Шаг 3. Работа с man
Откройте справку по команде ls:

bash
man ls
Внутри man:

Найдите слово hidden через /hidden.

Перейдите к следующему совпадению через n.

Выйдите через q.

Откройте справку по формату файла /etc/fstab:

bash
man 5 fstab
Откройте справку по административной команде mount:

bash
man 8 mount
Найдите все команды, связанные с network:

bash
apropos network
Получите краткую информацию о команде:

bash
whatis ls
whatis cp

##### Шаг 4. Работа с info
Откройте главное меню info:

bash
info
Перейдите к разделу Coreutils:

Нажмите m, введите coreutils, нажмите Enter.

Найдите в дереве ls:

Используйте n и p для навигации.

Нажмите Enter на ссылке ls invocation.

Выйдите через q.

Откройте справку по ls напрямую:

bash
info ls

##### Шаг 5. Документация установленных пакетов
Найдите документацию по пакету coreutils:

bash
dpkg -L coreutils | grep /usr/share/doc
Просмотрите README:

bash
zcat /usr/share/doc/coreutils/README.gz | less
Просмотрите changelog:

bash
zcat /usr/share/doc/coreutils/changelog.Debian.gz | head -50
Проверьте наличие примеров конфигураций:

bash
ls /usr/share/doc/*/examples/ 2>/dev/null | head

#### 🛡️ Особенности Astra Linux SE
Специфические утилиты: Многие штатные утилиты Astra Linux (fly-admin-*, astra-*) имеют встроенную справку через --help и описаны в электронной справке и на wiki.

Документация по безопасности: Для сертифицированных версий SE выпускаются отдельные руководства по безопасности, содержащие информацию о МКЦ, ЗПС и режиме «Киоск».

Ограничения МКЦ: В SE с включённым МКЦ доступ к некоторым справочным ресурсам (например, к защищённым разделам wiki или документации) может требовать высокого уровня целостности.

Локальная документация: На установочном диске Astra Linux часто присутствует полный комплект документации в формате PDF, доступный без интернета.

Обновление базы man: После установки новых пакетов рекомендуется выполнять sudo mandb для обновления базы данных справочных страниц.
