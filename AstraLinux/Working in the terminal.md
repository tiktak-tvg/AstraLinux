### Работа в терминале 
Это базовый навык администрирования Astra Linux. Понимание типов терминалов, умение настраивать их и эффективно использовать инструменты вроде screen напрямую влияет на удобство и безопасность работы с системой.

#### 🖥️ Типы терминалов
В Linux, и в частности в Astra Linux, термин «терминал» охватывает несколько разных сущностей, которые важно различать.

Тип терминала	   | Описание	                | Имена устройств
---------------- | ------------------------ | -----------------------------------------------------------
Аппаратный	 | Физическое устройство (монитор с клавиатурой, подключённые напрямую к машине) или эмулятор в виртуальной среде (например, консоль KVM).	 | /dev/console, /dev/ttyS0 (последовательный порт)
Виртуальный (VT)	  | Виртуальные консоли, доступные на самой машине. Переключение между ними — Ctrl+Alt+F1…F7.	 | /dev/tty1 … /dev/tty63
Псевдотерминал (PTY)	  | Эмуляция терминала в графической среде (окно терминала) или при удалённом подключении по SSH. Состоит из «ведущей» (master) и «ведомой» (slave) частей.	 | /dev/pts/0, /dev/pts/1, …

Проверка текущего терминала:

```bash
# Узнать, в каком терминале вы работаете
tty
# Для виртуальной консоли: /dev/tty1
# Для окна терминала в графике: /dev/pts/0

# Показать родительский терминал
who am i
```
В Astra Linux SE переключение между виртуальными консолями выполняется стандартным сочетанием Ctrl+Alt+F<N>, где <N> — номер консоли (обычно от 1 до 7).

#### ⚙️ Настройка терминалов
Управление параметрами терминала (дисциплиной линии) осуществляется утилитой stty. Дисциплина линии — это набор правил, определяющих, как терминал обрабатывает ввод и вывод: эхо-вывод символов, обработка специальных символов (Ctrl+C, Ctrl+D), размер окна и т.д.

Просмотр текущих настроек
```bash
# Показать все настройки текущего терминала
stty -a
```
Вывод содержит скорость передачи, количество строк и столбцов, а также значения специальных символов.

Основные команды stty

Команда	         | Действие
---------------- | ------------------------
stty -a	 | Показать все текущие настройки.
stty -F /dev/ttyS0 115200	  | Установить скорость для указанного устройства.
stty sane	  | Сбросить терминал в «разумное» состояние (полезно после сбоя).
stty echo / stty -echo	 | Включить/выключить эхо-вывод вводимых символов.
stty intr ^C	  | Установить символ прерывания (по умолчанию Ctrl+C).
stty eof ^D	 | Установить символ конца файла (по умолчанию Ctrl+D).
stty rows 40 cols 120	  | Установить размеры окна (строки × столбцы).

Пример: настройка терминала для работы с последовательным портом

```bash
# Просмотр текущих настроек
sudo stty -F /dev/ttyS0 -a

# Установка скорости 115200 бод
sudo stty -F /dev/ttyS0 115200

# Проверка
sudo stty -F /dev/ttyS0 -a | grep speed
```
Пример: сброс терминала после сбоя

Если после запуска программы терминал перестал отображать вводимые символы или реагировать на клавиши, выполните:

```bash
# Сброс в нормальное состояние
stty sane

# Или принудительно вернуть эхо
stty echo
```
Файл /etc/securetty
В Astra Linux SE доступ root-пользователя к терминалам контролируется файлом /etc/securetty. В нём перечислены терминалы, с которых разрешён вход root.

```bash
# Просмотр разрешённых терминалов для root
cat /etc/securetty
```
Пример содержимого:
```text
console
tty1
tty2
ttyS0
```
Если нужно разрешить root-вход с определённого терминала, добавьте его имя в этот файл. Если файл отсутствует или пуст, root не сможет войти ни с одного терминала.

#### 🖥️ Утилита screen
**screen** — это терминальный мультиплексор. Он позволяет создавать несколько виртуальных терминалов в рамках одной сессии, отсоединяться от них и подключаться снова, не прерывая работу запущенных процессов.

Установка
```bash
sudo apt install screen
```
Основные команды

Команда	         | Действие
---------------- | ------------------------
screen	 | Создать новую сессию.
screen -S my_session	 | Создать сессию с именем my_session.
screen -ls	 | Список активных сессий.
screen -r my_session	 | Подключиться к существующей сессии.
screen -d -r my_session | 	Отсоединить другие сессии и подключиться.
exit	 | Завершить текущую сессию (внутри screen).

Управляющие комбинации (внутри screen)

Все команды начинаются с ``Ctrl+a``, за которой следует управляющая клавиша.

Комбинация	     | Действие
---------------- | ------------------------
Ctrl+a c	  | Создать новое окно.
Ctrl+a n	  | Переключиться на следующее окно.
Ctrl+a p	  | Переключиться на предыдущее окно.
Ctrl+a 0…9	    | Переключиться на окно с указанным номером.
Ctrl+a d	  | Отсоединиться от сессии (процессы продолжают работать).
Ctrl+a "	  | Показать список всех окон для выбора.
Ctrl+a S	  | Разделить окно по горизонтали.
<img width="98" height="23" alt="image" src="https://github.com/user-attachments/assets/0be4ae62-3288-4a50-b37f-c03e2059a04c" /> | Разделить окно по вертикали.
Ctrl+a Tab	  | Переключиться между областями разделённого окна.
Ctrl+a ?	  | Показать справку по всем комбинациям.

Типичный сценарий использования
```bash
# 1. Запустить SSH-сессию на удалённом сервере
ssh user@server

# 2. Создать screen-сессию
screen -S work

# 3. Запустить длительный процесс (например, бэкап)
tar -czf /backup/archive.tar.gz /home

# 4. Отсоединиться от сессии
# Нажать Ctrl+a, затем d

# 5. Выйти из SSH (процесс продолжает работать на сервере)
exit

# 6. Позже снова подключиться по SSH
ssh user@server

# 7. Восстановить сессию
screen -r work
```
Важно: В Astra Linux SE для запуска screen может потребоваться использовать формат ``systemd-run --scope --user screen``, особенно при работе в защищённых сессиях.

#### 🚪 Вход в систему и выход из системы
Вход в систему

Графический вход: Стандартный вход через экран приветствия (Fly DM). Введите логин и пароль.

Консольный вход:

- Переключитесь на виртуальную консоль: Ctrl+Alt+F1 (или F2–F7).
- Введите логин и пароль.
- Для выхода — команда exit или logout.

Удалённый вход (SSH):

```bash
ssh username@hostname
```
Выход из системы
Способ           |	Команда / действие
---------------- | ------------------------
Из графической сессии	  | «Пуск» → «Завершение работы» → «Выход»
Из консоли	 | exit или logout
Завершение работы	  | sudo shutdown -h now
Перезагрузка	  | sudo reboot

Команды для смены пользователя
```bash
# Переключиться на другого пользователя
su - username

# Выполнить команду от имени другого пользователя
sudo -u username command

# Вернуться к предыдущему пользователю
exit
```
#### ⌨️ Управляющие (escape) последовательности
Управляющие последовательности — это специальные комбинации символов, которые терминал интерпретирует как команды управления, а не как текст. Они начинаются с символа ESC (\x1B или ^[).

Основные управляющие последовательности
Последовательность	| Действие
---------------- | ------------------------
\033[H	 | Переместить курсор в верхний левый угол.
\033[2J	 | Очистить экран.
\033[31m | Установить красный цвет текста.
\033[0m	 | Сбросить все атрибуты (цвет, жирность).
\033[1m	 | Жирный текст.
\033[K	 | Очистить строку от курсора до конца.
\033[s / \033[u	 | Сохранить/восстановить позицию курсора.

Пример использования в bash:

```bash
# Вывод красного текста
echo -e "\033[31mЭто красный текст\033[0m"

# Очистка экрана
echo -e "\033[2J\033[H"

# Вывод текста в верхней строке с очисткой
printf "\033[1;1H\033[KСтатус: OK"
```
Управляющие символы (control characters)
Это одиночные символы, вводимые с Ctrl:

Комбинация	     | Символ	                  | Действие
---------------- | ------------------------ | --------------------
Ctrl+C	 | ^C (0x03)	  | Прервать текущий процесс (SIGINT).
Ctrl+D	 | ^D (0x04)	  | Конец файла (EOF).
Ctrl+Z	 | ^Z (0x1A)		| Приостановить процесс (SIGTSTP).
Ctrl+L	 | ^L (0x0C)	  | Очистить экран.
Ctrl+A	 | ^A (0x01)	  | Переместить курсор в начало строки.
Ctrl+E	 | ^E (0x05)	  | Переместить курсор в конец строки.
Ctrl+U	 | ^U (0x15)	  | Удалить строку до курсора.
Ctrl+K	 | ^K (0x0B)	  | Удалить строку после курсора.

#### 💻 Практическая работа
Цель: Освоить вход/выход из системы, работу с разными типами терминалов, настройку дисциплины линии, использование escape-последовательностей и утилиты screen.

##### Шаг 1. Вход в систему и определение терминала
Войдите в систему через графический интерфейс.

Откройте окно терминала (например, Ctrl+Alt+T).

Определите, в каком терминале вы работаете:

```bash
tty
# Пример вывода: /dev/pts/0 (псевдотерминал)
```
Переключитесь на виртуальную консоль:
```text
Ctrl+Alt+F2
```
Войдите в систему (введите логин и пароль).

Определите терминал:
```bash
tty
# Пример вывода: /dev/tty2 (виртуальный терминал)
```
Вернитесь в графическую сессию: Ctrl+Alt+F7 (или F1).

##### Шаг 2. Настройка дисциплины линии
Просмотрите текущие настройки:
```bash
stty -a
```
Отключите эхо-вывод:
```bash
stty -echo
```
Теперь вводимые символы не отображаются. Введите любую команду — вы её не увидите.

Включите эхо обратно:
```bash
stty echo
```
Измените символ прерывания на Ctrl+X:
```bash
stty intr ^X
```
Проверьте: запустите sleep 100 и нажмите Ctrl+X — процесс должен прерваться.

Верните стандартный символ:
```bash
stty intr ^C
```
Сбросьте терминал в нормальное состояние:
```bash
stty sane
```
##### Шаг 3. Использование escape-последовательностей
Выведите красный текст:
```bash
echo -e "\033[31mВнимание!\033[0m Это красный текст."
```
Выведите текст с жирным шрифтом:
```bash
echo -e "\033[1mЖирный текст\033[0m"
```
Очистите экран:
```bash
echo -e "\033[2J\033[H"
```
Выведите текст в определённой позиции:
```bash
printf "\033[5;10HТекст в позиции (5,10)"
```
##### Шаг 4. Работа с утилитой screen
Установите screen:
```bash
sudo apt install screen
```
Создайте новую сессию с именем practice:
```bash
screen -S practice
```
Внутри screen запустите длительный процесс:
```bash
ping -c 1000 8.8.8.8
```
Отсоединитесь от сессии: нажмите Ctrl+a, затем d.

Убедитесь, что сессия существует:
```bash
screen -ls
# Вывод: There is a screen on: ... practice
```
Подключитесь к сессии снова:
```bash
screen -r practice
```
Убедитесь, что ping продолжает выполняться.

Создайте второе окно: Ctrl+a, затем c.

Выполните во втором окне:
```bash
ls -la /etc
```
Переключитесь обратно на первое окно: Ctrl+a, затем p (или n).

Завершите ping: Ctrl+C.

Выйдите из screen: введите exit.

##### Шаг 5. Выход из системы
В консоли введите:
```bash
exit
```
Вернитесь в графическую сессию и выполните выход через меню «Пуск».

#### 🛡️ Особенности Astra Linux SE
Мандатный контроль целостности (МКЦ): В SE с включённым МКЦ использование screen может требовать запуска через systemd-run --scope --user screen, чтобы обеспечить корректную работу в рамках мандатных ограничений.

/etc/securetty: Доступ root к терминалам строго контролируется этим файлом. Убедитесь, что нужные терминалы добавлены, если требуется root-вход.

Режим восстановления: Для работы в консоли режима восстановления («синяя консоль», bterm) может потребоваться предварительная установка пакета bterm и соответствующих шрифтов.

Логирование терминальных сессий: В защищённых конфигурациях рекомендуется вести аудит действий, выполняемых в терминале, с помощью script или систем аудита (auditd).
