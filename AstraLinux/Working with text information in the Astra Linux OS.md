### Работа с текстовой информацией в ОС Astra Linux
**Обработка текста** — одна из сильнейших сторон Linux. В Astra Linux доступен полный арсенал стандартных утилит: перенаправление потоков, фильтры, регулярные выражения и мощные потоковые редакторы sed и awk. Эти инструменты позволяют анализировать логи, извлекать данные, автоматизировать отчёты и строить сложные конвейеры обработки.

#### 🔀 Перенаправление стандартных потоков в файл или из файла
В Linux каждый процесс имеет три стандартных потока:

Поток	         | Дескриптор	    | Назначение
---------------- | ---------------- | --------------
stdin	         | 0	             | Стандартный ввод   (клавиатура).
stdout	         | 1	             | Стандартный вывод     (терминал).
stderr	         | 2	             | Стандартный вывод ошибок   (терминал).

**Операторы перенаправления**

Оператор	     | Действие	                            | Пример
---------------- | ------------------------------------ | --------------
'>'                | stdout в файл (перезапись).	        | ls > list.txt
'>>'	             | stdout в файл (дозапись).	        | echo "new" >> list.txt
'<'	             | stdin из файла.		                | wc -l < /etc/passwd
'2>'	             | stderr в файл.		                | find / -name x 2> errors.txt
'2>>'	             | stderr в файл (дозапись).		    | cmd 2>> errors.txt
'&>'	             | stdout и stderr в файл.		        | cmd &> all.log
'2>&1'	         | Объединить stderr с stdout.		    | cmd > all.log 2>&1
'&>>'	             | stdout и stderr в файл (дозапись).   | cmd &>> all.log

Примеры:
```bash
# Только stdout в файл, ошибки — на экран
ls /etc /nonexistent > output.txt

# Только stderr в файл, результат — на экран
ls /etc /nonexistent 2> errors.txt

# Всё в один файл
ls /etc /nonexistent > all.log 2>&1

# Отбросить ошибки в «никуда»
find / -name "*.conf" 2> /dev/null

# Порядок важен: 2>&1 > file — НЕПРАВИЛЬНО
# Правильно: > file 2>&1
```
> Важно: Порядок перенаправлений имеет значение. cmd > file 2>&1 перенаправит stdout в файл, затем stderr — туда же. А cmd 2>&1 > file сначала свяжет stderr с текущим stdout (терминалом), а потом перенаправит stdout в файл — ошибки останутся на экране.

#### 🔗 Перенаправление стандартных потоков между процессами
Конвейер (pipe) — это механизм, при котором stdout одной команды становится stdin другой.

```text
команда1 | команда2 | команда3
```
Примеры:
```bash
# Подсчёт количества файлов в /etc
ls /etc | wc -l

# Поиск процессов ssh
ps aux | grep ssh

# Сортировка списка пользователей
cut -d: -f1 /etc/passwd | sort

# Топ-5 самых больших файлов в /var
du -ah /var 2>/dev/null | sort -rh | head -5

# Цепочка из четырёх команд
cat /var/log/syslog | grep "error" | sort | uniq -c | sort -rn
```
**Команда tee — разветвление потока**

tee читает stdin и пишет одновременно в stdout и в файл(ы).
```bash
# Вывод на экран и запись в файл
ls -la | tee listing.txt

# Дозапись в файл
command | tee -a log.txt

# Запись в несколько файлов
command | tee file1.txt file2.txt
```
#### 📖 Команды для просмотра текстовых файлов
Команда	         | Назначение	                        | Особенности
---------------- | ------------------------------------ | --------------
cat	             | Вывести файл целиком.	            | Для небольших файлов.
less	         | Постраничный просмотр.	            | Навигация, поиск, поддержка больших файлов.

head	         | Первые N строк (по умолчанию 10).	| head -20 file
tail	         | Последние N строк.	                | tail -f file — слежение в реальном времени.
nl	             | Вывод с нумерацией строк.	        | 
tac	             | Вывод файла в обратном порядке.	    |

Примеры:
```bash
# Просмотр файла с навигацией
less /etc/passwd
# Внутри: /поиск, n — следующее, q — выход

# Последние 20 строк с нумерацией
tail -20 /var/log/syslog | nl

# Слежение за логом в реальном времени
tail -f /var/log/syslog

# Первые 5 строк
head -5 /etc/passwd
```
#### 🔧 Команды-фильтры
Фильтры читают stdin, преобразуют данные и пишут в stdout.

Команда	         | Назначение	                        | Пример
---------------- | ------------------------------------ | --------------
grep	         | Поиск строк по шаблону.	             | grep "error" log.txt
sed	             | Потоковый редактор.	                 | sed 's/old/new/g' file
awk	             | Обработка по полям.	                 | awk '{print $1}' file
cut	             | Вырезание полей.	                     | cut -d: -f1 /etc/passwd
sort	         | Сортировка строк.	                 | sort file.txt
uniq	         | Удаление соседних дубликатов.	     | sort file | uniq -c
wc	             | Подсчёт строк, слов, символов.	     | wc -l file.txt
tr	             | Замена символов.	                     | tr 'a-z' 'A-Z'
head / tail	     | Первые/последние строки.	         | 
rev	             | Реверс каждой строки.	         | 
paste	         | Объединение файлов по столбцам.	         | 
split	         | Разбиение файла на части.	         | 

Примеры:
```bash
# Сортировка с подсчётом дубликатов
sort /etc/passwd | cut -d: -f7 | uniq -c

# Подсчёт строк, слов, символов
wc /etc/passwd
# 42 100 2500 /etc/passwd

# Замена регистра
echo "hello" | tr 'a-z' 'A-Z'    # HELLO

# Вырезание первого поля
cut -d: -f1 /etc/passwd | head -5
```
#### 🔤 Регулярные выражения
Регулярные выражения (regex) — это язык описания шаблонов для поиска и замены текста. Различают базовые (BRE) и расширенные (ERE) регулярные выражения.

**Базовые метасимволы**

Символ	         | Значение	                            | Пример
---------------- | ------------------------------------ | --------------
.	 | Любой один символ.	 | a.c → abc, a1c
*	 | Ноль или более предыдущих символов.	 | ab*c → ac, abc, abbc
^	 | Начало строки.	 | ^root
$	 | Конец строки.	 | bash$
[...]	 | Один из символов.	 | [abc]
[^...]	 | Любой, кроме указанных.	 | [^0-9]
[a-z]	 | Диапазон.	 | [a-zA-Z]
\	 | Экранирование.	 | \. — буквальная точка
\{n,m\}	 | От n до m повторений (BRE).	 | a\{2,4\}

**Расширенные метасимволы (ERE)**

Символ	         | Значение	                      
---------------- | ------------------------------------ 
+	 | Одно или более повторений.
?	 | Ноль или одно повторение.
|	 | Альтернатива (ИЛИ).
( )	 | Группировка.
{n,m}	 | От n до m повторений.

Примеры:
```bash
# Базовые
grep "^root" /etc/passwd          # строки, начинающиеся с root
grep "bash$" /etc/passwd          # строки, заканчивающиеся на bash
grep "r..t" /etc/passwd           # r, любые 2 символа, t

# Расширенные (grep -E)
grep -E "^(root|admin)" /etc/passwd
grep -E "[0-9]{3,}" file.txt
grep -E "colou?r" file.txt        # color или colour
```
#### 🔍 Потоковый фильтр grep
grep — основной инструмент поиска строк по шаблону.

**Основные параметры**

Параметр	     | Действие	                      
---------------- | ------------------------------------ 
-i	             | Игнорировать регистр.
-v	             | Инвертировать (строки, НЕ содержащие шаблон).
-c	             | Только количество совпадений.
-n	             | Показывать номера строк.
-l	             | Только имена файлов с совпадениями.
-r	             | Рекурсивный поиск по каталогам.
-E	             | Расширенные регулярные выражения.
-F	             | Поиск фиксированной строки (без regex).
-w	             | Искать целое слово.
-A N	         | Показать N строк после совпадения.
-B N	         | Показать N строк до совпадения.
-C N	         | Показать N строк вокруг.
--color=auto	 | Подсветка совпадений.

Примеры:
```bash
# Поиск с номерами строк
grep -n "error" /var/log/syslog

# Инвертированный поиск
grep -v "^#" /etc/ssh/sshd_config | grep -v "^$"

# Рекурсивный поиск
grep -rn "listen" /etc/nginx/

# Подсчёт вхождений
grep -c "GET" /var/log/apache2/access.log

# Контекст
grep -C 2 "fail" /var/log/auth.log

# Расширенные regex
grep -E "(error|fail|warn)" /var/log/syslog

# Только имена файлов
grep -rl "Astra" /etc/
```
#### ✏️ Потоковые редакторы sed и awk
**sed — Stream Editor**

sed — потоковый редактор для автоматической обработки текста: замены, удаления, вставки строк без открытия файла в редакторе.

Синтаксис: sed [опции] 'команды' файл

Основные команды:

Команда	         | Действие	                      
---------------- | ------------------------------------ 
s/old/new/	 | Замена первого вхождения в строке.
s/old/new/g	 | Замена всех вхождений.
s/old/new/2	 | Замена второго вхождения.
N d	         | Удалить строку N.
N p	         | Напечатать строку N.
N i text	 | Вставить текст перед строкой N.
N a text	 | Вставить текст после строки N.
N c text	 | Заменить строку N текстом.

Опции:

Опция	         | Действие	                      
---------------- | ------------------------------------ 
-n	             | Подавить автоматический вывод (использовать с p).
-i	             | Редактировать файл «на месте».
-e	             | Несколько команд.
-E	             | Расширенные regex.

Примеры:
```bash
# Замена во всех строках
sed 's/old/new/g' file.txt

# Замена только в строках, содержащих "pattern"
sed '/pattern/s/old/new/g' file.txt

# Удаление строк с комментариями
sed '/^#/d' /etc/ssh/sshd_config

# Удаление пустых строк
sed '/^$/d' file.txt

# Печать только нужных строк (с -n)
sed -n '5,10p' file.txt

# Вставка строки после 3-й
sed '3a\Новая строка' file.txt

# Редактирование файла «на месте» с резервной копией
sed -i.bak 's/old/new/g' file.txt

# Несколько команд
sed -e 's/foo/bar/' -e 's/baz/qux/' file.txt

# Извлечение IP-адресов
sed -nE 's/.*([0-9]{1,3}\.){3}[0-9]{1,3}.*/\1/p' file.txt
```
**awk — язык обработки текста**

awk — это полноценный язык программирования для обработки структурированного текста. Основная идея — разбиение строки на поля по разделителю.

Синтаксис: awk [опции] 'программа' файл

Основные переменные:

Переменная	     | Значение
---------------- | ----------------
$0	             | Вся строка.
$1, $2, ...	     | Поля строки.
NF	             | Количество полей в строке.
NR	             | Номер текущей строки (общий).
FNR	             | Номер строки в текущем файле.
FS	             | Разделитель полей (по умолчанию — пробел).
OFS	             | Разделитель полей вывода.
RS	             | Разделитель записей.

Опции:

Опция	         | Действие
---------------- | ----------------
-F	             | Задать разделитель полей.
-v var=value	 | Передать переменную.

Примеры:

```bash
# Вывести первое и третье поля
awk '{print $1, $3}' file.txt

# Указать разделитель
awk -F: '{print $1, $7}' /etc/passwd

# Фильтр по условию
awk -F: '$3 > 1000 {print $1}' /etc/passwd

# Подсчёт строк
awk 'END {print NR}' file.txt

# Сумма значений
awk '{sum += $1} END {print sum}' numbers.txt

# Среднее
awk '{sum += $1; n++} END {print sum/n}' numbers.txt

# Замена разделителя вывода
awk -F: 'BEGIN {OFS=","} {print $1, $7}' /etc/passwd

# Форматированный вывод
awk -F: '{printf "%-15s %s\n", $1, $7}' /etc/passwd

# Несколько условий
awk -F: '$3 > 100 && $3 < 1000 {print $1, $3}' /etc/passwd

# Замена в поле
awk -F: '{$3 = $3 + 1; print}' /etc/passwd

# Использование переменных из оболочки
awk -v limit=1000 -F: '$3 > limit {print $1}' /etc/passwd
```
Пример сложного сценария: подсчёт IP-адресов в логе.

```bash
awk '{print $1}' /var/log/apache2/access.log \
    | sort | uniq -c | sort -rn | head -10
```
#### 📝 Текстовый редактор vim
vim (Vi IMproved) — мощный модальный редактор, доступный в Astra Linux по умолчанию.

Установка
```bash
sudo apt install vim
```
Режимы vim
Режим	         | Назначение	    | Вход
---------------- | ---------------- | ----------------
Нормальный	 | Навигация, команды.	 | Esc
Вставки	     | Ввод текста.	 | i, a, o и др.
Визуальный	 | Выделение текста.	 | v, V, Ctrl+V
Командный	 | Команды :	 | :

Основные команды
Навигация (нормальный режим):

Клавиша          | Действие
---------------- | -------------------- 
h, j, k, l		 | Влево, вниз, вверх, вправо.
w, b		 | К следующему/предыдущему слову.
0, $		 | В начало/конец строки.
gg, G		 | В начало/конец файла.
:N		         | Перейти к строке N.

Редактирование:

Клавиша          | Действие
---------------- | -------------------- 
i, a	 | Вставка до/после курсора.
o, O	 | Новая строка ниже/выше.
x, dd	 | Удалить символ/строку.
yy, p	 | Скопировать/вставить строку.
u, Ctrl+r	 | Отменить/повторить.
:w, :q, :wq, :q!	 | Сохранить, выйти, сохранить и выйти, выйти без сохранения.

Поиск и замена:

Команда  	     | Действие
---------------- | -------------------- 
/pattern	 | Поиск вперёд.
?pattern	 | Поиск назад.
n, N	     | Следующее/предыдущее совпадение.
:%s/old/new/g	 | Замена во всём файле.
:%s/old/new/gc	 | Замена с подтверждением.

Пример работы:

```bash
vim /etc/hosts
# Внутри:
# i — войти в режим вставки
# ... ввести текст ...
# Esc — вернуться в нормальный режим
# :wq — сохранить и выйти
```

#### 💻 Практическая работа
Цель: Освоить регулярные выражения, grep, sed, awk и построение командных строк.

##### Шаг 1. Подготовка тестовых данных
```bash
# Создаём тестовый файл
cat > /tmp/users.txt << EOF
ivanov:Иван:ivanov@example.com:1001:/home/ivanov:/bin/bash
petrov:Пётр:petrov@example.com:1002:/home/petrov:/bin/bash
sidorov:Сидор:1003:/home/sidorov:/bin/sh
admin:Администратор:admin@example.com:0:/root:/bin/bash
guest:Гость:guest@example.com:1004:/home/guest:/bin/false
EOF

cat /tmp/users.txt
```
##### Шаг 2. Регулярные выражения и grep
Найдите строки, начинающиеся с admin:
```bash
grep "^admin" /tmp/users.txt
```
Найдите строки, содержащие bash в конце:
```bash
grep "bash$" /tmp/users.txt
```
Найдите строки, содержащие email:
```bash
grep -E "[a-zA-Z0-9._]+@[a-zA-Z0-9.]+\.[a-z]{2,}" /tmp/users.txt
```
Найдите строки с UID от 1000 до 1999:
```bash
grep -E ":(1[0-9]{3}):" /tmp/users.txt
```
Инвертируйте поиск (без bash):
```bash
grep -v "bash" /tmp/users.txt
```
Подсчитайте количество пользователей:
```bash
grep -c ":" /tmp/users.txt
```
Покажите номера строк с ошибками:
```bash
grep -n "" /tmp/users.txt
```
##### Шаг 3. Редактирование потоков с помощью sed
Замените bash на zsh:
```bash
sed 's/bash/zsh/g' /tmp/users.txt
```
Удалите строки, начинающиеся с guest:
```bash
sed '/^guest/d' /tmp/users.txt
```
Покажите только строки с 2 по 4:
```bash
sed -n '2,4p' /tmp/users.txt
```
Добавьте заголовок в начало файла:
```bash
sed '1i # Список пользователей' /tmp/users.txt
```
Замените разделитель : на |:
```bash
sed 's/:/ | /g' /tmp/users.txt
```
Отредактируйте файл «на месте» с резервной копией:
```bash
cp /tmp/users.txt /tmp/users.bak
sed -i.bak 's|/bin/bash|/bin/zsh|g' /tmp/users.txt
diff /tmp/users.bak /tmp/users.txt
```
Удалите пустые строки и комментарии:
```bash
sed -e '/^#/d' -e '/^$/d' /tmp/users.txt
```
##### Шаг 4. Использование awk для составления командных строк
Выведите только имена пользователей (первое поле):
```bash
awk -F: '{print $1}' /tmp/users.txt
```
Выведите имена и оболочки:
```bash
awk -F: '{print $1, $NF}' /tmp/users.txt
```
Выведите пользователей с UID < 1000:
```bash
awk -F: '$4 < 1000 {print $1, $4}' /tmp/users.txt
```
Выведите пользователей с bash:
```bash
awk -F: '$NF ~ /bash$/ {print $1}' /tmp/users.txt
```
Подсчитайте количество пользователей:
```bash
awk 'END {print "Всего:", NR}' /tmp/users.txt
```
Отформатируйте вывод:
```bash
awk -F: '{printf "%-15s %s\n", $1, $NF}' /tmp/users.txt
```
Передайте переменную из оболочки:
```bash
LIMIT=1000
awk -v limit=$LIMIT -F: '$4 > limit {print $1}' /tmp/users.txt
```
##### Шаг 5. Построение сложных командных строк
Топ-10 IP-адресов в логе:
```bash
awk '{print $1}' /var/log/apache2/access.log 2>/dev/null \
    | sort | uniq -c | sort -rn | head -10
```
Подсчёт HTTP-кодов ответов:
```bash
awk '{print $9}' /var/log/apache2/access.log 2>/dev/null \
    | sort | uniq -c | sort -rn
```
Список пользователей, отсортированный по UID:
```bash
awk -F: '$4 >= 1000 {print $4, $1}' /tmp/users.txt | sort -n
```
Извлечение email-адресов:
```bash
grep -oE "[a-zA-Z0-9._]+@[a-zA-Z0-9.]+\.[a-z]{2,}" /tmp/users.txt
```
Замена email на [hidden]:
```bash
sed -E 's/[a-zA-Z0-9._]+@[a-zA-Z0-9.]+\.[a-z]{2,}/[hidden]/g' /tmp/users.txt
```
Подсчёт слов в файле:
```bash
cat /tmp/users.txt | tr -s ' ' '\n' | sort | uniq -c | sort -rn
```
##### Шаг 6. Работа с vim
Откройте файл:
```bash
vim /tmp/users.txt
```
Выполните:

**G** — перейти в конец файла.

**gg** — в начало.

#### 🛡️ Особенности Astra Linux SE
Мандатный контроль доступа (МКЦ): В SE с включённым МКЦ доступ к файлам логов и конфигураций определяется мандатными метками. Команды grep, sed, awk работают стандартно, но доступ к защищённым файлам может быть ограничен.

Локализация: В Astra Linux русские символы в текстовых файлах могут занимать 2 байта (UTF-8). При использовании cut, awk и sed учитывайте это — для корректной работы с многобайтовыми символами используйте LC_ALL=C или соответствующие опции.

Штатные утилиты: Для работы с текстом в Astra Linux доступны все стандартные GNU-утилиты. Специфических замен нет.

Логирование: При автоматизации обработки логов (/var/log/syslog, /var/log/auth.log) помните, что в SE с МКЦ доступ к некоторым журналам может требовать высокого уровня целостности.

vim vs vi: В Astra Linux по умолчанию может быть установлен vim-tiny (урезанная версия). Для полного функционала установите sudo apt install vim
