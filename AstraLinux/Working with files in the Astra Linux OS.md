### Работа с файлами в ОС Astra Linux
**Файловая система** — это фундамент любой операционной системы. В Astra Linux, как и в других Linux-системах, реализована единая иерархическая модель, где всё начинается от корневого каталога /. Понимание этой структуры, типов файлов и инструментов для работы с ними — базовый навык администратора.

#### 🗂️ Иерархия файловой системы
Файловая система Astra Linux представляет собой древовидную структуру, вершиной которой является корневой каталог /. В эту точку монтируется системный диск, и от неё отсчитываются все остальные пути.

**Ключевые особенности иерархии:**

- Единое дерево: Все диски, разделы и съёмные носители подключаются (монтируются) в определённые точки этого дерева. Отдельных «дисков C: и D:» не существует.
- Всё есть файл: Этот принцип означает, что не только документы и программы, но и устройства, каналы связи и даже информация о процессах представлены в виде файлов.

Регистр зависимость: ``File.txt и file.txt`` — это два разных файла.

#### 📦 Файлы, индексные дескрипторы, блоки данных
В файловых системах Linux (ext4, XFS) физическое хранение файла разделено на две части: индексный дескриптор (inode) и блоки данных.

Компонент	      | Что содержит	    | Где хранится
--------------- | ----------------- | -------------------
Индексный дескриптор (inode)	  | Метаданные: права доступа, владелец, группа, размер, временные метки, счётчик ссылок, указатели на блоки данных. Не содержит имени файла.	 | В специальной таблице inode файловой системы.
Блоки данных	  | Само содержимое файла (текст, бинарный код, изображение).	 | В блоках данных на диске.

Ключевые следствия:

- Имя файла хранится в каталоге, а не в inode. Каталог — это таблица соответствия «имя → номер inode».
- Один inode может иметь несколько имён (жёсткие ссылки). Пока счётчик ссылок в inode > 0, данные не удаляются.

**Номер inode можно увидеть командой ls -i или stat**.

```bash
# Просмотр номера inode
ls -i /etc/passwd
# 1234567 /etc/passwd

# Полная информация об inode
stat /etc/passwd
```
#### 📄 Типы файлов
В Linux существует несколько типов файлов. Тип файла определяется первым символом в выводе команды ls -l.

Тип	            | Обозначение	      | Описание	        | Пример
--------------- | ----------------- | ----------------- | -------------------------------------
Обычный файл	  | -	 | Текстовые, исполняемые, бинарные файлы, архивы.  | /etc/passwd, /bin/bash
Каталог	 | d	  | Специальный файл, содержащий таблицу «имя → inode».	  | /home, /etc
Символическая ссылка	  | l	 | Указатель на другой файл или каталог.	  | /usr/bin/python -> python3
Символьное устройство	  | c	 | Устройства с последовательным доступом (мышь, терминал). | 	/dev/tty0, /dev/input/mouse0
Блочное устройство	    | b	 | Устройства с произвольным доступом (диски).	| /dev/sda, /dev/vda
Именованный канал (FIFO)| p	 | Канал для меж процессного взаимодействия.	  | /run/systemd/initctl/fifo
Сокет	                  | s	 | Конечная точка для сетевого взаимодействия.	 | /run/systemd/journal/socket

**Пример вывода ls -l:**

```text
-rw-r--r--  1 user user   1234 Jan 1 12:00 document.txt    # обычный файл
drwxr-xr-x  2 user user   4096 Jan 1 12:00 mydir           # каталог
lrwxrwxrwx  1 root root      7 Jan 1 12:00 python -> python3  # символическая ссылка
crw-rw-rw-  1 root root   1, 3 Jan 1 12:00 /dev/null       # символьное устройство
brw-rw----  1 root disk   8, 0 Jan 1 12:00 /dev/sda        # блочное устройство
```
#### 📏 Стандарт иерархии ФС (FHS)
**FHS (Filesystem Hierarchy Standard)** — это стандарт, унифицирующий расположение файлов и каталогов в Linux-системах. Он определяет, какие типы данных должны находиться в тех или иных каталогах, что обеспечивает совместимость между дистрибутивами.

**Основные принципы FHS:**
```bash
/ — корень, точка монтирования системного диска.

Статические данные отделены от изменяемых.

Общие данные отделены от локальных.

Каталоги, критичные для загрузки, находятся в корне (/bin, /lib, /sbin).
```
#### 📁 Назначение основных каталогов
Каталог	        | Назначение
--------------- | ----------------- 
/	     | Корневой каталог — начало всей иерархии.
/bin	 | Основные пользовательские команды (утилиты), необходимые для загрузки и работы в однопользовательском режиме.
/boot	 | Файлы загрузчика GRUB, образы ядра, initrd.
/dev	 | Файлы устройств (псевдофайловая система devtmpfs).
/etc	 | Конфигурационные файлы системы и приложений.
/home	 | Домашние каталоги пользователей.
/lib	 | Общие библиотеки и модули ядра.
/media | Точка автоматического монтирования сменных носителей (CD/DVD).
/mnt	 | Точка для ручного монтирования внешних носителей.
/opt	 | Дополнительное программное обеспечение.
/proc	 | Виртуальная ФС procfs — информация о ядре и процессах.
/root	 | Домашний каталог пользователя root.
/run	 | Временные данные (PID-файлы, сокеты).
/sbin	 | Системные команды для администрирования.
/srv	 | Данные для сервисов (веб-сервер, FTP).
/sys	 | Виртуальная ФС sysfs — информация об устройствах.
/tmp	 | Временные файлы (очищается при перезагрузке).
/usr	 | Пользовательские программы и данные.
/var	 | Изменяемые данные (логи, очереди, кэш).

#### 🧭 Команды навигации по файловой системе
Команда	        | Назначение	      | Пример
--------------- | ----------------- | -----------------
pwd	   | Показать текущий каталог.	 | pwd → /home/user

ls	   | Список файлов в каталоге.	 | ls -la

**Полезные параметры ls:**

Параметр	      | Действие
--------------- | -----------------
-l	            | Длинный формат (права, владелец, размер, дата).
-a	            | Показать скрытые файлы (начинающиеся с .).

-i	            | Показать номера inode.
-t	            | Сортировка по времени изменения.
-S	            | Сортировка по размеру.

#### 📝 Команды создания файлов
Команда	        | Назначение	      | Пример
--------------- | ----------------- | -----------------
touch	  | Создать пустой файл или обновить временные метки.	    | touch newfile.txt

nano	  | Создать и отредактировать файл.	  | nano file.txt
vim	    | Создать и отредактировать файл.	  | vim file.txt

#### 🔍 Поиск файлов

Команда	        | Назначение	      | Особенности
--------------- | ----------------- | -----------------
find	   | Поиск в реальном времени по дереву каталогов.	 | Медленнее, но всегда актуален.
locate	 | Поиск по предварительно созданной базе данных.	 | Очень быстрый, но база может устареть.
which	   | Поиск исполняемого файла в PATH.	 | which ls → /usr/bin/ls
whereis	 | Поиск бинарников, исходников и man-страниц.	 | whereis ls

**Примеры find:**
```bash
# Поиск по имени
find /home -name "*.txt"

# Поиск по типу (только файлы)
find /var -type f -name "*.log"

# Поиск по размеру (больше 100 МБ)
find /home -type f -size +100M

# Поиск по времени изменения (за последние 7 дней)
find /var/log -type f -mtime -7

# Поиск с выполнением команды
find /tmp -name "*.tmp" -exec rm {} \;
```
**Примеры locate:**
```bash
# Быстрый поиск по имени
locate passwd

# Обновление базы данных locate
sudo updatedb
```
Важно: В Astra Linux утилита locate может быть не установлена по умолчанию. Для установки: sudo apt install mlocate.

#### 📂 Использование Менеджера файлов и Midnight Commander
**Менеджер файлов (fly-fm)**

В Astra Linux встроен графический Менеджер файлов (утилита fly-fm), который запускается из меню «Пуск» или командой fly-fm в терминале.

Основные возможности:

- Навигация по файловой системе с помощью боковой панели и адресной строки.
- Создание, копирование, перемещение, удаление файлов и каталогов.
- Поиск файлов в выбранной папке через контекстное меню.
- Настройка отображения (значки, список, фильтры).

**Midnight Commander (mc)**

Midnight Commander — это мощный двух панельный файловый менеджер с текстовым интерфейсом, работающий в терминале.

Установка:
```bash
sudo apt install mc
```
Запуск:
```bash
mc
```
Основные горячие клавиши:

Клавиша	        | Действие
--------------- | ----------------- 
F3	            | Просмотреть файл.
F4	            | Редактировать файл.
F5	            | Копировать.
F6	            | Переместить/переименовать.
F7	            | Создать каталог.
F8	            | Удалить.
Shift+F4	      | Создать новый файл.
Tab	            | Переключение между панелями.
Ctrl+O	        | Показать/скрыть терминал.
F10	            | Выход.

#### 💻 Практическая работа
Цель: Освоить навигацию по файловой системе, создание файлов разных типов, операции с файлами и поиск.

##### Шаг 1. Навигация по файловой системе
Определите текущий каталог:
```bash
pwd
```
Перейдите в корневой каталог:
```bash
cd /
```
Просмотрите содержимое корня:
```bash
ls -la
```
Перейдите в /etc и просмотрите файлы:
```bash
cd /etc
ls -la | head -20
```
Вернитесь в домашний каталог:
```bash
cd ~
pwd
```
Перейдите в предыдущий каталог:
```bash
cd -
```
##### Шаг 2. Создание файлов разных типов
Создайте пустой файл:
```bash
touch empty.txt
ls -l empty.txt
```
Создайте текстовый файл с содержимым:
```bash
echo "Это тестовый файл" > text.txt
cat text.txt
```
Создайте многострочный файл:
```bash
cat > multiline.txt << EOF
Первая строка
Вторая строка
Третья строка
EOF
cat multiline.txt
```
Создайте каталог:
```bash
mkdir testdir
ls -ld testdir
```
Создайте вложенные каталоги:
```bash
mkdir -p testdir/subdir1/subdir2
tree testdir
```
Создайте символическую ссылку:
```bash
ln -s /etc/passwd passwd_link
ls -l passwd_link
```
Создайте жёсткую ссылку:
```bash
ln text.txt hardlink.txt
ls -li text.txt hardlink.txt
```
##### Шаг 3. Операции с файлами
Скопируйте файл:
```bash
cp text.txt copy.txt
ls -l copy.txt
```
Переименуйте файл:
```bash
mv copy.txt renamed.txt
ls -l renamed.txt
```
Переместите файл в каталог:
```bash
mv renamed.txt testdir/
ls testdir/
```
Удалите файл:
```bash
rm empty.txt
ls empty.txt 2>/dev/null || echo "Файл удалён"
```
Удалите каталог с содержимым:
```bash
rm -r testdir
ls -d testdir 2>/dev/null || echo "Каталог удалён"
```
##### Шаг 4. Поиск файлов
Найдите все .conf файлы в /etc:
```bash
find /etc -name "*.conf" 2>/dev/null | head -10
```
Найдите файлы размером более 10 МБ в /var:
```bash
find /var -type f -size +10M 2>/dev/null | head -5
```
Найдите файлы, изменённые за последние 7 дней:
```bash
find /home -type f -mtime -7 2>/dev/null | head -10
```
Используйте locate (если установлен):
```bash
sudo updatedb
locate passwd | head -10
```
Найдите исполняемый файл команды:
```bash
which ls
whereis ls
```
##### Шаг 5. Работа с Midnight Commander
Установите mc:
```bash
sudo apt install mc
```
Запустите:
```bash
mc
Создайте каталог mc_test (F7).

Войдите в него (Enter).

Создайте новый файл (Shift+F4), введите текст, сохраните (F2), выйдите (F10).

Скопируйте файл в родительский каталог (F5).

Просмотрите файл (F3).

Удалите файл (F8).

Выйдите из mc (F10).
```
##### Шаг 6. Работа с Менеджером файлов
Запустите Менеджер файлов через «Пуск» → «Менеджер файлов» или командой:
```bash
fly-fm &
```
- Перейдите в домашний каталог.
- Создайте новый текстовый файл через контекстное меню.
- Скопируйте его в другой каталог.
- Найдите файл через функцию поиска.

#### 🛡️ Особенности Astra Linux SE
Мандатный контроль доступа (МКЦ): В Special Edition с включённым МКЦ доступ к файлам определяется не только правами rwx, но и мандатными метками (уровень конфиденциальности, категория). Файлы с высоким уровнем целостности могут быть недоступны в сессии с низким уровнем.

Разделяемые каталоги: В Astra Linux используются специальные каталоги для совместной работы пользователей с разными мандатными метками. Эти каталоги создаются автоматически при установке ОС.

Проверка целостности: Подсистема контроля целостности (astra-ic) отслеживает изменения критичных файлов. При работе с файлами в защищённых конфигурациях это может влиять на доступность.

Специфические утилиты: Для работы с файлами в SE могут использоваться штатные утилиты fly-fm (графический менеджер) и mc (Midnight Commander), доступные через репозитории Astra Linux.
