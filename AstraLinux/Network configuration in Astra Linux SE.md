Настройка сети в Astra Linux SE — это многоуровневый процесс, который можно выполнять как через графический интерфейс, так и из командной строки. В основе лежит управление сетевыми интерфейсами с помощью служб NetworkManager или networking.

🌐 Сетевой интерфейс
Сетевой интерфейс — это точка подключения устройства к сети. В Astra Linux SE, как и в других Linux-системах, интерфейсы имеют имена, такие как eth0 (проводной), wlan0 (беспроводной) или lo (локальная петля). Для просмотра доступных интерфейсов используются команды:

ip link show — просмотр всех сетевых интерфейсов.

nmcli device status — просмотр интерфейсов, управляемых NetworkManager.

⚙️ Настройка сетевых интерфейсов с помощью Network Manager
NetworkManager — это служба, которая является фактическим стандартом управления сетевыми интерфейсами в Astra Linux. Она устанавливается и запускается автоматически, получая контроль над внешними интерфейсами.

Графический интерфейс
Для настройки через графический интерфейс (например, в среде Fly) можно использовать:

Апплет NetworkManager: Кликните правой кнопкой мыши по значку сети в системном трее и выберите «Изменить соединения...».

Панель управления: Перейдите в «Пуск» → «Панель управления» → «Сеть» → «Сетевые соединения».

В открывшемся окне можно добавить новое соединение (проводное, Wi-Fi, VPN и т.д.), указать IP-адрес (статический или DHCP), шлюз и DNS-серверы.

Командная строка (nmcli)
Для управления через терминал используется утилита nmcli. Основные команды:

Задача	Команда
Просмотр всех соединений	nmcli connection show
Просмотр устройств	nmcli device status
Создание статического соединения	nmcli con add type ethernet ifname eth0 con-name "static" ip4 192.168.1.10/24 gw4 192.168.1.1
Изменение соединения	nmcli con mod "static" ipv4.dns "8.8.8.8,8.8.4.4"
Переключение на статический IP	nmcli con mod "static" ipv4.method manual
Активация соединения	nmcli con up "static"
Перезагрузка конфигурации	sudo nmcli con reload
Важно: Для добавления или изменения соединений пользователь должен состоять в группе netdev.

🔧 Настройка сетевых интерфейсов с помощью ifup/ifdown
Этот метод является альтернативой NetworkManager и управляется через файл /etc/network/interfaces. Он удобен для серверных конфигураций.

Пример настройки статического IP для интерфейса eth0:

Откройте файл /etc/network/interfaces:

bash
sudo nano /etc/network/interfaces
Добавьте или измените секцию для eth0:

text
auto eth0
iface eth0 inet static
    address 192.168.1.10
    netmask 255.255.255.0
    gateway 192.168.1.1
Проверьте корректность файла:

bash
sudo ifquery eth0
Перезапустите интерфейс:

bash
sudo ifdown eth0 && sudo ifup eth0
Эту команду лучше выполнять одной строкой, чтобы не потерять соединение при удалённой работе.

⚠️ Важно: Службы NetworkManager и networking могут конфликтовать. Перед использованием ifup/ifdown рекомендуется отключить управление интерфейсом со стороны NetworkManager, например, закомментировав его в файле /etc/NetworkManager/NetworkManager.conf или выполнив sudo systemctl --now mask NetworkManager.

🔍 Команды диагностики сети
Для проверки правильности настроек и поиска неисправностей используются следующие утилиты:

Команда	Назначение
ip a	Показать все IP-адреса на интерфейсах
ip r	Показать таблицу маршрутизации
ping <хост>	Проверить доступность узла
traceroute <хост>	Проследить маршрут до узла
ss -tuln	Показать открытые порты и сокеты
netstat -tuln	Устаревший аналог ss
nmcli con show	Показать состояние соединений NetworkManager
💻 Практическая работа
Цель: Определить сетевые параметры, настроить интерфейс через NetworkManager и ifup/ifdown, проверить настройки.

Шаг 1. Определение сетевых параметров
Просмотрите доступные интерфейсы:

bash
ip link show
nmcli device status
Узнайте текущие IP-адреса и маршруты:

bash
ip a
ip r
Шаг 2. Настройка через NetworkManager (nmcli)
Создайте новое проводное соединение с именем my-static на интерфейсе eth0:

bash
sudo nmcli con add type ethernet ifname eth0 con-name my-static ip4 192.168.100.50/24 gw4 192.168.100.1
Установите DNS-серверы:

bash
sudo nmcli con mod my-static ipv4.dns "8.8.8.8,8.8.4.4"
Убедитесь, что метод получения IP — ручной:

bash
sudo nmcli con mod my-static ipv4.method manual
Активируйте соединение:

bash
sudo nmcli con up my-static
Проверьте настройки:

bash
ip a show eth0
nmcli con show my-static
Шаг 3. Настройка через ifup/ifdown
Отключите управление интерфейсом eth0 со стороны NetworkManager (если необходимо):

bash
sudo nmcli dev set eth0 managed no
Отредактируйте файл /etc/network/interfaces, добавив статическую конфигурацию (пример выше).

Проверьте и примените настройки:

bash
sudo ifquery eth0
sudo ifdown eth0 && sudo ifup eth0
Проверьте, что IP-адрес изменился:

bash
ip a show eth0
Шаг 4. Проверка правильности настроек
Проверьте доступность шлюза:

bash
ping -c 4 192.168.100.1
Проверьте доступность внешнего ресурса (если есть интернет):

bash
ping -c 4 8.8.8.8
Проверьте разрешение имён (DNS):

bash
nslookup ya.ru
Просмотрите таблицу маршрутизации:

bash
ip r
💎 Особенности Astra Linux SE
Приоритет NetworkManager: В Astra Linux SE NetworkManager является рекомендуемой и основной службой управления сетью. Использование ifup/ifdown без отключения NetworkManager может привести к конфликтам.

Мандатный контроль (МКЦ): В Special Edition с включённым МКЦ настройка сети может требовать высокого уровня целостности. Некоторые команды могут быть недоступны в сессиях с низким уровнем.

IPv6: В Astra Linux SE IPv6 по умолчанию отключён на уровне службы networking. Для его включения требуются дополнительные действия.

Графические инструменты: В состав ОС входят фирменные графические утилиты настройки, такие как «Панель управления» → «Сеть», что упрощает работу администратора.
