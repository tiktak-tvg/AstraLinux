### Управление устройствами хранения данных в Astra Linux 
Управление устройствами хранения данных в Astra Linux выходит на новый уровень, когда стандартных разделов становится недостаточно. Здесь на помощь приходят LVM для гибкого управления пространством и LUKS для защиты данных шифрованием.

### 📚 Управление логическими томами (LVM)
LVM (Logical Volume Manager) — это прослойка между физическими дисками и файловой системой, которая позволяет создавать логические тома, легко изменять их размер и объединять ресурсы нескольких дисков.

### 🧱 Создание физических томов (PV)
Первым шагом физические диски или разделы необходимо инициализировать как физические тома (Physical Volume, PV). В качестве примера используется диск /dev/vdb.

bash
# Создание физического тома на диске /dev/vdb
sudo pvcreate /dev/vdb

Для просмотра созданных физических томов используется команда pvs.

### 🗂️ Создание групп томов (VG)
Физические тома объединяются в группу томов (Volume Group, VG), которая представляет собой единый пул пространства. Например, можно расширить существующую группу VG, добавив в неё новый физический том.

bash
# Добавление физического тома /dev/vdb в группу томов VG
sudo vgextend VG /dev/vdb

### 💽 Создание логических томов (LV)
Внутри группы томов создаются логические тома (Logical Volume, LV). Это аналог разделов, но с гораздо большей гибкостью. Можно создать том нужного размера:

bash
# Создание логического тома my_lv размером 500 МБ в группе VG
sudo lvcreate -L 500M -n my_lv VG
Также можно создать том, занимающий всё свободное пространство в группе.

### 📈 Изменение размеров логических томов и файловых систем
Одно из главных преимуществ LVM — возможность изменять размер томов «на лету».

Увеличение логического тома и файловой системы:

bash
# Увеличение логического тома и файловой системы на нём на 10 ГБ
sudo lvextend -r -L +10G /dev/VG/my_lv
Уменьшение (для ext4 требуется размонтирование).

### 📸 Создание снимков состояния (snapshot)
Снимок (snapshot) — это мгновенная копия логического тома на момент создания. Он очень полезен для резервного копирования или тестирования обновлений. Для создания снимка требуется свободное место в группе томов.

bash
# Создание снимка lvsnap для тома /dev/astra-vg/root размером 4 ГБ
sudo lvcreate -L 4GB -s -n lvsnap /dev/astra-vg/root

Снимок можно смонтировать и получить доступ к данным на момент его создания. Позже снимок можно удалить с помощью lvremove.

### 🔐 Шифрование дисков (LUKS)
LUKS (Linux Unified Key Setup) — это стандарт де-факто для шифрования дисков в Linux. В Astra Linux для работы с LUKS используется утилита cryptsetup.

### 🛡️ Создание зашифрованного раздела
Форматирование раздела как LUKS-контейнера:

bash
# Создание LUKS-контейнера на разделе /dev/sdb1
sudo cryptsetup luksFormat /dev/sdb1
Система запросит подтверждение и пароль.

Открытие (разблокировка) контейнера:

bash
# Открытие контейнера и создание устройства /dev/mapper/mydisk
sudo cryptsetup luksOpen /dev/sdb1 mydisk
Создание файловой системы на расшифрованном устройстве:

bash
sudo mkfs.ext4 /dev/mapper/mydisk
Теперь с этим устройством можно работать как с обычным диском.

Для шифрования логических томов LVM можно использовать опцию --encrypted при создании тома, указав версию LUKS (например, --luks-version=luks2) и парольную фразу.

### ⚙️ Настройка и контроль работы дисковых устройств
В Astra Linux управление подключением съемных устройств контролируется политиками безопасности. Например, монтирование непривилегированными пользователями может быть запрещено или требовать ввода пароля администратора через специальное правило ru.rusbitech.noudisksmount.pkla. Для управления устройствами и правилами существует графический модуль «Устройства и правила» в утилите astra-systemsettings.

### 💻 Практическая работа: LVM, Snapshot и Шифрование
Цель: Создать логический том LVM, сделать его снимок и настроить зашифрованный раздел.

Важно: Все операции выполняются на дополнительном диске (например, /dev/vdb). Не используйте диск с установленной ОС.

Шаг 1. Создание логического тома LVM
bash
# 1.1. Создаём физический том на новом диске
sudo pvcreate /dev/vdb

# 1.2. Создаём новую группу томов (или расширяем существующую)
sudo vgcreate my_vg /dev/vdb

# 1.3. Создаём логический том размером 2 ГБ
sudo lvcreate -L 2G -n my_lv my_vg

# 1.4. Создаём файловую систему на томе
sudo mkfs.ext4 /dev/my_vg/my_lv
Шаг 2. Создание снимка состояния (Snapshot)
bash
# 2.1. Создаём снимок нашего логического тома размером 512 МБ
sudo lvcreate -L 512M -s -n my_snapshot /dev/my_vg/my_lv

# 2.2. Проверяем, что снимок создан
sudo lvs
Шаг 3. Создание и настройка зашифрованного раздела
bash
# 3.1. Создаём LUKS-контейнер на разделе (например, /dev/sdc1)
sudo cryptsetup luksFormat /dev/sdc1

# 3.2. Открываем контейнер
sudo cryptsetup luksOpen /dev/sdc1 secure_data

# 3.3. Создаём файловую систему на расшифрованном устройстве
sudo mkfs.ext4 /dev/mapper/secure_data

# 3.4. Монтируем и проверяем
sudo mkdir -p /mnt/secure
sudo mount /dev/mapper/secure_data /mnt/secure
df -h /mnt/secure
Для автоматического монтирования при загрузке потребуется добавить запись в /etc/crypttab и /etc/fstab.

### 💎 Ключевые особенности Astra Linux
Сертифицированные ФС: Для учтённых носителей в защищённых системах рекомендуется использовать только ext2/ext3/ext4 (и xfs с определённых версий).

Мандатный контроль: В Special Edition с включённым МКЦ все операции с дисками и шифрованием должны выполняться с высоким уровнем целостности (например, через sudo -s).

Графические инструменты: Для управления устройствами и правилами используйте astra-systemsettings → «Устройства и правила».
