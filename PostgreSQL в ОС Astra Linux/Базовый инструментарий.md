### Базовый инструментарий: установка, управление, psql
#### 1. Установка PostgreSQL в Astra Linux
В состав Astra Linux Special Edition включена СУБД PostgreSQL. Версия зависит от релиза ОС:

Версия Astra Linux SE	Версия PostgreSQL
- 1.7	PostgreSQL 11
- 1.8	PostgreSQL 15

Установка из базового репозитория:

```bash
sudo apt update
sudo apt install postgresql-11
```
Для установки конкретной версии:

```bash
sudo apt install postgresql-11=11.10-astra.se5
```

> Важно: при подключении расширенного компонента astra-ce защищённая версия СУБД, доработанная для взаимодействия с КСЗ Astra Linux, будет заменена на стандартную незащищённую версию.

Для установки дополнительных расширений:

```bash
sudo apt install postgresql-contrib
```
#### 2. Управление службой PostgreSQL
После установки служба postgresql запускается автоматически. Управление осуществляется через systemd:

```bash
# Проверка статуса
systemctl status postgresql

# Перезапуск службы
sudo systemctl restart postgresql

# Остановка
sudo systemctl stop postgresql

# Запуск
sudo systemctl start postgresql

# Включение автозагрузки
sudo systemctl enable postgresql

Проверка прослушиваемых портов:

bash
ss -tunelp | grep uid:`id -u postgres`
```
#### 3. Первичная настройка
Установка пароля администратора СУБД:

```bash
sudo su - postgres
psql -c "alter user postgres with password 'пароль'"
exit
```
Пароль заключается в одинарные кавычки, вся команда — в двойные.

Настройка удалённого доступа — в файле /etc/postgresql/11/main/postgresql.conf:

```text
listen_addresses = '*'
Допустимые значения:

'*' — все сетевые интерфейсы (IPv4 и IPv6);

'0.0.0.0' — только IPv4;

'::' — только IPv6;

'192.168.1.2,10.0.0.2' — конкретные адреса.
```

Настройка аутентификации — в файле /etc/postgresql/11/main/pg_hba.conf:

```text
# TYPE  DATABASE  USER  ADDRESS         METHOD
local   all       all                   peer
host    all       all   127.0.0.1/32    md5
host    all       all   192.168.122.0/24 md5
```
После изменений перезапустить службу:

```bash
sudo systemctl restart postgresql
```
#### 4. Работа с psql
psql — интерактивный терминал PostgreSQL для выполнения SQL-запросов и административных команд.

Подключение к базе данных:

```bash
# От имени служебного пользователя postgres
sudo -u postgres psql

# Подключение к конкретной базе
psql -d mydb

# Подключение с указанием хоста, порта и пользователя
psql -h 127.0.0.1 -p 5432 -U postgres -d mydb
```
Выполнение команд без входа в интерактивный режим:

```bash
psql -c "SELECT version();"
psql -d mydb -f script.sql
```
#### 5. Основные мета команды psql
Мета команды начинаются с обратной косой черты (\) и обрабатываются самим psql, а не сервером PostgreSQL.

Команда	     | Описание
------------ | ------------------------
\l	 | Список всех баз данных
\c   | dbname	Подключиться к базе данных
\dt	 | Список таблиц
\d   | table	Описание структуры таблицы
\du	 | Список ролей и пользователей
\dn	 | Список схем
\dp	 | Права доступа к таблицам
\dx	 | Список расширений
\h	 | Справка по SQL-командам
\?	 | Справка по метакомандам
\q	 | Выход из psql
\timing	 | Включить/выключить замер времени выполнения
\x	 | Расширенный режим вывода

Пример работы с psql:

```sql
-- Подключиться к базе
\c mydb

-- Посмотреть список таблиц
\dt

-- Посмотреть структуру таблицы employees
\d employees

-- Посмотреть список ролей
\du

-- Выполнить запрос
SELECT * FROM employees;

-- Выйти
\q
```
#### 6. Создание базы данных и пользователя
```sql
-- Создать базу данных
CREATE DATABASE mydb LC_COLLATE 'ru_RU.utf8' LC_CTYPE 'ru_RU.utf8' TEMPLATE template0;

-- Создать пользователя
CREATE USER myuser WITH PASSWORD 'password';

-- Выдать права на базу
GRANT ALL PRIVILEGES ON DATABASE mydb TO myuser;

-- Сменить владельца
ALTER DATABASE mydb OWNER TO myuser;
```
#### 7. Устранение типичных проблем
Проблема	Решение
Проблема     | Решение
------------ | ------------------------
could not change directory to '/home/'	 | Использовать sudo su - postgres вместо sudo su postgres
СУБД не запускается после обновления	 | В /etc/postgresql/15/main/postgresql.conf установить ac_audit_mode = default и перезапустить
Ошибка доступа к мандатным меткам	 | Установить zero_if_notfound: yes в /etc/parsec/mswitch.conf
Нет доступа к каталогу macdb	 | Выполнить setfacl -m u:postgres:rx /etc/parsec/macdb
