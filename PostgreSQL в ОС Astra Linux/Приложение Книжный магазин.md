### Приложение «Книжный магазин»: схема данных
#### 1. Общее описание
Приложение «Книжный магазин» — типовой учебный пример реляционной базы данных, демонстрирующий проектирование схемы, нормализацию, создание связей и работу с SQL. Схема охватывает основные бизнес-процессы: учёт книг, авторов, издательств, категорий, клиентов, заказов и продаж.

#### 2. Логическая модель данных
##### 2.1. Основные сущности

Сущность            | Описание
------------------- | -------------------------
Автор (authors)	 | Авторы книг
Издательство (publishers)	 | Издательства
Категория (categories)	 | Жанры и тематики книг
Книга (books)	 | Информация о книгах
Связь книга-автор (book_authors)	 | Многие-ко-многим между книгами и авторами
Клиент (customers)	 | Покупатели
Сотрудник (employees)	 | Продавцы/менеджеры
Заказ (orders)	 | Заказы клиентов
Позиция заказа (order_items)	 | Состав заказа
Поставка (supplies)	 | Поступления книг на склад
Склад (stock)	 | Остатки книг

##### 2.2. Связи между сущностями
```text
authors ←→ book_authors ←→ books
                              │
publishers ←──────────────────┤
                              │
categories ←──────────────────┤
                              │
                              ├──→ order_items ←── orders ←── customers
                              │                      │
                              │                      └──→ employees
                              │
                              └──→ supplies ←── publishers
                              │
                              └──→ stock
```

Связь                | Тип                       | Описание
-------------------- | ------------------------- | -------------------------
books — authors	     | M:N	                     | Одна книга может иметь несколько авторов, один автор — несколько книг
books — publishers	 | M:1	                     | У одной книги одно издательство
books — categories	 | M:1	                     | У одной книги одна категория
orders — customers	 | M:1	                     | Один клиент — много заказов
orders — employees	 | M:1	                     | Один сотрудник обрабатывает много заказов
orders — order_items | 1:M	                     | Один заказ содержит много позиций
order_items — books	 | M:1	                     | Одна позиция ссылается на одну книгу
stock — books     	 | 1:1	                     | Одна запись остатка на одну книгу

#### 3. Физическая модель (DDL)

##### 3.2. Справочники
Авторы:

```sql
CREATE TABLE authors (
    author_id   SERIAL PRIMARY KEY,
    last_name   VARCHAR(100) NOT NULL,
    first_name  VARCHAR(100) NOT NULL,
    middle_name VARCHAR(100),
    birth_date  DATE,
    country     VARCHAR(100),
    biography   TEXT
);

CREATE INDEX idx_authors_last_name ON authors(last_name);
Издательства:

sql
CREATE TABLE publishers (
    publisher_id SERIAL PRIMARY KEY,
    name         VARCHAR(200) NOT NULL UNIQUE,
    city         VARCHAR(100),
    address      VARCHAR(300),
    phone        VARCHAR(30),
    email        VARCHAR(100),
    website      VARCHAR(200)
);
Категории:

sql
CREATE TABLE categories (
    category_id SERIAL PRIMARY KEY,
    name        VARCHAR(100) NOT NULL UNIQUE,
    parent_id   INTEGER REFERENCES categories(category_id),
    description TEXT
);
```
Иерархическая структура категорий: parent_id ссылается на родительскую категорию (например, «Художественная литература» → «Детективы»).

##### 3.3. Книги и авторы
Книги:

```sql
CREATE TABLE books (
    book_id       SERIAL PRIMARY KEY,
    isbn          VARCHAR(20) UNIQUE NOT NULL,
    title         VARCHAR(300) NOT NULL,
    publisher_id  INTEGER NOT NULL REFERENCES publishers(publisher_id),
    category_id   INTEGER REFERENCES categories(category_id),
    publication_year INTEGER CHECK (publication_year BETWEEN 1500 AND 2100),
    pages         INTEGER CHECK (pages > 0),
    binding       VARCHAR(50),
    price         NUMERIC(10,2) NOT NULL CHECK (price >= 0),
    cost_price    NUMERIC(10,2) CHECK (cost_price >= 0),
    description   TEXT,
    cover_image   VARCHAR(300),
    created_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_books_title ON books(title);
CREATE INDEX idx_books_publisher ON books(publisher_id);
CREATE INDEX idx_books_category ON books(category_id);
```
Связь книга-автор (M:N):

```sql
CREATE TABLE book_authors (
    book_id   INTEGER NOT NULL REFERENCES books(book_id) ON DELETE CASCADE,
    author_id INTEGER NOT NULL REFERENCES authors(author_id) ON DELETE CASCADE,
    role      VARCHAR(50) DEFAULT 'author',
    PRIMARY KEY (book_id, author_id)
);
```
Поле role позволяет указать роль: author, translator, editor, illustrator.

##### 3.4. Клиенты и сотрудники
Клиенты:

```sql
CREATE TABLE customers (
    customer_id SERIAL PRIMARY KEY,
    last_name   VARCHAR(100) NOT NULL,
    first_name  VARCHAR(100) NOT NULL,
    middle_name VARCHAR(100),
    email       VARCHAR(150) UNIQUE NOT NULL,
    phone       VARCHAR(30),
    birth_date  DATE,
    address     VARCHAR(300),
    city        VARCHAR(100),
    postal_code VARCHAR(20),
    discount    NUMERIC(5,2) DEFAULT 0 CHECK (discount BETWEEN 0 AND 100),
    registered_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    is_active   BOOLEAN DEFAULT TRUE
);

CREATE INDEX idx_customers_email ON customers(email);
CREATE INDEX idx_customers_last_name ON customers(last_name);
```
Сотрудники:

```sql
CREATE TABLE employees (
    employee_id SERIAL PRIMARY KEY,
    last_name   VARCHAR(100) NOT NULL,
    first_name  VARCHAR(100) NOT NULL,
    middle_name VARCHAR(100),
    position    VARCHAR(100) NOT NULL,
    email       VARCHAR(150) UNIQUE,
    phone       VARCHAR(30),
    hire_date   DATE NOT NULL DEFAULT CURRENT_DATE,
    salary      NUMERIC(10,2) CHECK (salary >= 0),
    is_active   BOOLEAN DEFAULT TRUE
);
```
##### 3.5. Заказы
Заказы:

```sql
CREATE TABLE orders (
    order_id     SERIAL PRIMARY KEY,
    customer_id  INTEGER NOT NULL REFERENCES customers(customer_id),
    employee_id  INTEGER REFERENCES employees(employee_id),
    order_date   TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    status       VARCHAR(30) NOT NULL DEFAULT 'new'
                 CHECK (status IN ('new', 'processing', 'shipped', 'delivered', 'cancelled')),
    total_amount NUMERIC(12,2) DEFAULT 0 CHECK (total_amount >= 0),
    discount     NUMERIC(5,2) DEFAULT 0,
    delivery_address VARCHAR(300),
    delivery_method  VARCHAR(50),
    payment_method   VARCHAR(50),
    comment      TEXT
);

CREATE INDEX idx_orders_customer ON orders(customer_id);
CREATE INDEX idx_orders_date ON orders(order_date);
CREATE INDEX idx_orders_status ON orders(status);
```
Позиции заказа:

```sql
CREATE TABLE order_items (
    order_item_id SERIAL PRIMARY KEY,
    order_id      INTEGER NOT NULL REFERENCES orders(order_id) ON DELETE CASCADE,
    book_id       INTEGER NOT NULL REFERENCES books(book_id),
    quantity      INTEGER NOT NULL CHECK (quantity > 0),
    unit_price    NUMERIC(10,2) NOT NULL CHECK (unit_price >= 0),
    discount      NUMERIC(5,2) DEFAULT 0
);

CREATE INDEX idx_order_items_order ON order_items(order_id);
CREATE INDEX idx_order_items_book ON order_items(book_id);
```
##### 3.6. Склад и поставки
Склад:

```sql
CREATE TABLE stock (
    book_id       INTEGER PRIMARY KEY REFERENCES books(book_id) ON DELETE CASCADE,
    quantity      INTEGER NOT NULL DEFAULT 0 CHECK (quantity >= 0),
    reserved      INTEGER NOT NULL DEFAULT 0 CHECK (reserved >= 0),
    min_quantity  INTEGER DEFAULT 5,
    last_updated  TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```
Поставки:

```sql
CREATE TABLE supplies (
    supply_id    SERIAL PRIMARY KEY,
    publisher_id INTEGER NOT NULL REFERENCES publishers(publisher_id),
    supply_date  DATE NOT NULL DEFAULT CURRENT_DATE,
    invoice_number VARCHAR(50),
    total_amount NUMERIC(12,2) CHECK (total_amount >= 0),
    status       VARCHAR(30) DEFAULT 'pending'
                 CHECK (status IN ('pending', 'received', 'cancelled'))
);

CREATE TABLE supply_items (
    supply_item_id SERIAL PRIMARY KEY,
    supply_id      INTEGER NOT NULL REFERENCES supplies(supply_id) ON DELETE CASCADE,
    book_id        INTEGER NOT NULL REFERENCES books(book_id),
    quantity       INTEGER NOT NULL CHECK (quantity > 0),
    cost_price     NUMERIC(10,2) NOT NULL CHECK (cost_price >= 0)
);
```
#### 4. Представления (Views)
Актуальные остатки книг:

```sql
CREATE VIEW v_book_stock AS
SELECT
    b.book_id,
    b.title,
    b.isbn,
    b.price,
    s.quantity,
    s.reserved,
    (s.quantity - s.reserved) AS available,
    s.min_quantity,
    CASE WHEN s.quantity - s.reserved < s.min_quantity
         THEN 'требуется заказ'
         ELSE 'достаточно'
    END AS stock_status
FROM books b
LEFT JOIN stock s ON b.book_id = s.book_id;
```
Информация о книгах с авторами:

```sql
CREATE VIEW v_books_full AS
SELECT
    b.book_id,
    b.title,
    b.isbn,
    p.name AS publisher,
    c.name AS category,
    b.publication_year,
    b.price,
    STRING_AGG(
        a.last_name || ' ' || LEFT(a.first_name, 1) || '.',
        ', ' ORDER BY ba.author_id
    ) AS authors
FROM books b
LEFT JOIN publishers p ON b.publisher_id = p.publisher_id
LEFT JOIN categories c ON b.category_id = c.category_id
LEFT JOIN book_authors ba ON b.book_id = ba.book_id
LEFT JOIN authors a ON ba.author_id = a.author_id
GROUP BY b.book_id, b.title, b.isbn, p.name, c.name, b.publication_year, b.price;
```
Продажи по клиентам:

```sql
CREATE VIEW v_customer_sales AS
SELECT
    c.customer_id,
    c.last_name || ' ' || c.first_name AS customer_name,
    COUNT(DISTINCT o.order_id) AS orders_count,
    COALESCE(SUM(o.total_amount), 0) AS total_spent,
    MAX(o.order_date) AS last_order_date
FROM customers c
LEFT JOIN orders o ON c.customer_id = o.customer_id
    AND o.status != 'cancelled'
GROUP BY c.customer_id, c.last_name, c.first_name;
```
#### 5. Функции и триггеры
Триггер обновления updated_at:

```sql
CREATE OR REPLACE FUNCTION update_timestamp()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = CURRENT_TIMESTAMP;
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_books_updated
    BEFORE UPDATE ON books
    FOR EACH ROW
    EXECUTE FUNCTION update_timestamp();
```
Пересчёт суммы заказа:

```sql
CREATE OR REPLACE FUNCTION recalc_order_total()
RETURNS TRIGGER AS $$
BEGIN
    UPDATE orders
    SET total_amount = (
        SELECT COALESCE(SUM(quantity * unit_price * (1 - discount/100)), 0)
        FROM order_items
        WHERE order_id = COALESCE(NEW.order_id, OLD.order_id)
    )
    WHERE order_id = COALESCE(NEW.order_id, OLD.order_id);
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_order_items_total
    AFTER INSERT OR UPDATE OR DELETE ON order_items
    FOR EACH ROW
    EXECUTE FUNCTION recalc_order_total();
```

#### 7. Полезные запросы
Топ-5 продаваемых книг:

```sql
SELECT b.title, SUM(oi.quantity) AS total_sold
FROM order_items oi
JOIN books b ON oi.book_id = b.book_id
JOIN orders o ON oi.order_id = o.order_id
WHERE o.status != 'cancelled'
GROUP BY b.book_id, b.title
ORDER BY total_sold DESC
LIMIT 5;
```
Книги, требующие пополнения склада:

```sql
SELECT b.title, s.quantity, s.min_quantity
FROM stock s
JOIN books b ON s.book_id = b.book_id
WHERE s.quantity < s.min_quantity;
```
Выручка по месяцам:

```sql
SELECT
    DATE_TRUNC('month', order_date) AS month,
    COUNT(*) AS orders_count,
    SUM(total_amount) AS revenue
FROM orders
WHERE status != 'cancelled'
GROUP BY month
ORDER BY month;
```
Авторы и количество их книг в магазине:

```sql
SELECT
    a.last_name || ' ' || a.first_name AS author,
    COUNT(ba.book_id) AS books_count
FROM authors a
LEFT JOIN book_authors ba ON a.author_id = ba.author_id
GROUP BY a.author_id, a.last_name, a.first_name
ORDER BY books_count DESC;
```
