### Кластерные технологии 
Это способ объединения нескольких серверов в единую вычислительную систему для повышения производительности, надежности и доступности. Вот обзор ключевых аспектов.

#### Что такое кластер?
*Кластер* — это группа компьютеров, объединенных высокоскоростными каналами связи в единую локальную сеть для совместного выполнения задач. Такая архитектура позволяет распределять нагрузку, обеспечивать отказоустойчивость и наращивать вычислительную мощность эффективнее, чем при использовании одного мощного сервера.

В типичный кластер входят: узел доступа, вычислительные узлы, файловый сервер, общая система хранения данных (СХД) и локальная сеть.

#### Виды кластеров
Кластеры классифицируются по решаемым задачам:
- Отказоустойчивые (High-Availability, HA): Обеспечивают бесперебойную работу сервисов. При отказе одного узла его задачи автоматически перераспределяются на другие. Используются для критичных баз данных, почтовых и финансовых серверов.
- С балансировкой нагрузки (Load Balancing): Равномерно распределяют входящие запросы между узлами для предотвращения перегрузок. Идеальны для веб-сайтов с высоким трафиком.
- Вычислительные (High-Performance Computing, HPC): Предназначены для сложных расчетов и научных симуляций. Узлы кластера работают синхронно над одной задачей.

#### Ключевые технологии кластеризации
Pacemaker и Corosync: Это стандартный стек для создания HA-кластеров в Linux.

- Corosync — это «фундамент», который обеспечивает обмен сообщениями между узлами, контроль их доступности и достижение кворума (согласия большинства).
- Pacemaker — это «мозг», который управляет ресурсами (службами, IP-адресами, файловыми системами) и принимает решения о запуске, остановке или перемещении сервисов при сбоях.
- Ceph: Распределенная файловая система, обеспечивающая объектное, блочное и файловое хранилище. Поддерживается в Astra Linux для создания отказоустойчивых систем хранения.
- HAProxy и Keepalived: HAProxy используется для балансировки нагрузки, а Keepalived — для мониторинга и обеспечения высокой доступности узлов и служб.

#### Кластеризация в Astra Linux
Astra Linux Special Edition включает в себя полный набор инструментов для построения кластеров высокой доступности:
- Готовая поддержка Pacemaker и Corosync: Это основной инструмент для создания отказоустойчивых конфигураций.
- Поддержка Ceph: Позволяет развертывать распределенные СХД.
- Средства резервирования: Поддерживается создание основного и резервных контроллеров домена (FreeIPA/ALD) с механизмами репликации.
- Интегрированный RAID: Программная реализация RAID встроена непосредственно в ядро системы.
